# ACI YAML Deployment

YAML deployment voor Azure Container Instances met container groups.

## Complete YAML Voorbeeld

```yaml
apiVersion: "2019-12-01"
location: eastus
name: containerName
properties:
  # Container groups: Containers delen lifecycle, resources, network en storage volumes
  # Voor Windows containers zijn alleen single-instance deployments toegestaan
  # Resources toegewezen aan host = som van alle aangevraagde resources
  # In dit geval: 2 CPUs en 2.5 GB RAM
  containers:
    - name: helloworld
      properties:
        environmentVariables:
          - name: "PUBLIC_ENV_VAR"
            value: "my-exposed-value"
          - name: "SECRET_ENV_VAR"
            secureValue: "my-secret-value"
        
        image: mcr.microsoft.com/hello-world
        
        ports:
          - port: 443
        
        resources:
          requests:
            cpu: 1.0
            memoryInGB: 1
        
        volumeMounts:
          - mountPath: /mnt/secrets
            name: secretvolume

    - name: hellofiles
      properties:
        environmentVariables: []
        
        image: mcr.microsoft.com/azuredocs/aci-hellofiles
        
        ports:
          - port: 80
        
        resources:
          requests:
            cpu: 1.0
            memoryInGB: 1.5
        
        volumeMounts:
          - mountPath: /aci/logs/
            name: filesharevolume

  osType: Linux # of Windows (voor single containers)
  restartPolicy: Always
  
  ipAddress:
    type: Public
    ports:
      - port: 443
      - port: 80
    dnsNameLabel: containerName

  volumes:
    - name: filesharevolume
      azureFile:
        sharename: acishare
        storageAccountName: <Storage account name>
        storageAccountKey: <Storage account key>
    
    - name: secretvolume
      secret:
        # NB: Secret values moeten Base64-encoded zijn!
        mysecret1: TXkgZmlyc3Qgc2VjcmV0IEZPTwo= # "My first secret FOO"
        mysecret2: TXkgc2Vjb25kIHNlY3JldCBCQVIK # "My second secret BAR"

tags: {}
type: Microsoft.ContainerInstance/containerGroups
```

---

## Container Groups Uitleg

### Wat delen containers?

**Lifecycle:**  
Alle containers starten en stoppen samen.

**Resources:**  
CPU en geheugen worden gedeeld op de host.

**Network:**  
- Delen een external IP adres
- Delen poorten
- Delen DNS naam

**Storage Volumes:**  
Kunnen dezelfde volumes mounten.

---

## Environment Variables

### Public Variables
```yaml
environmentVariables:
  - name: "PUBLIC_ENV_VAR"
    value: "my-exposed-value"
```

### Secure Variables
```yaml
environmentVariables:
  - name: "SECRET_ENV_VAR"
    secureValue: "my-secret-value"
```

---

## Volumes

### Azure File Share Volume
```yaml
volumes:
  - name: filesharevolume
    azureFile:
      sharename: acishare
      storageAccountName: mystorageaccount
      storageAccountKey: <key>
```

**Vereist:**
- Bestaand storage account
- Share name
- Storage account key

### Secret Volume
```yaml
volumes:
  - name: secretvolume
    secret:
      # Secrets moeten Base64-encoded zijn!
      mysecret1: TXkgZmlyc3Qgc2VjcmV0IEZPTwo=
      mysecret2: TXkgc2Vjb25kIHNlY3JldCBCQVIK
```

**Volume mounten:**
```yaml
volumeMounts:
  - mountPath: /mnt/secrets
    name: secretvolume
```

---

## Resources Toewijzing

### Per Container
```yaml
resources:
  requests:
    cpu: 1.0
    memoryInGB: 1.5
```

### Totaal voor Container Group

Als je 2 containers hebt:
- Container 1: 1.0 CPU, 1 GB RAM
- Container 2: 1.0 CPU, 1.5 GB RAM

**Totaal toegewezen:** 2.0 CPU, 2.5 GB RAM

## Networking

### IP Address Configuratie
```yaml
ipAddress:
  type: Public
  ports:
    - port: 443
    - port: 80
  dnsNameLabel: myuniquename
```

**Toegankelijk via:**
```
myuniquename.eastus.azurecontainer.io
```

## OS Type en Restart Policy

```yaml
osType: Linux # of Windows
restartPolicy: Always # of Never, OnFailure
```

**Windows beperkingen:**
- Alleen single-instance deployments

## Azure File Share Setup

Voordat je Azure File Share kunt gebruiken:

### 1. Storage account maken
```bash
az storage account create \
    --name mystorageaccount \
    --resource-group myResourceGroup \
    --location eastus \
    --sku Standard_LRS
```

### 2. File share maken
```bash
az storage share create \
    --name acishare \
    --account-name mystorageaccount
```

### 3. Storage account key ophalen
```bash
az storage account keys list \
    --account-name mystorageaccount \
    --resource-group myResourceGroup \
    --query "[0].value" \
    --output tsv
```

## Deployment

```bash
az container create \
    --name mycontainer \
    --resource-group myResourceGroup \
    --file deploy.yml
```
