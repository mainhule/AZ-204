# Dapr Integration

Dapr (Distributed Application Runtime) is geactiveerd per container app. De APIs zijn toegankelijk via een Dapr sidecar met HTTP of gRPC.

## Architectuur

Dapr's modulaire design staat toe dat componenten gedeeld of app-specifiek zijn, die kunnen verbinden met externe services en veilig toegang hebben tot configuratie metadata.

**Standaard gedrag:** Dapr-enabled container apps laden de volledige set van deployed componenten.

**Application scopes:** Om componenten alleen voor de juiste apps te laden.

---

## Dapr Inschakelen

```bash
az containerapp create \
    --dapr-enabled \
    --dapr-app-id myapp \
    --dapr-app-port 3000 \
    --name MyContainerApp \
    --resource-group MyResourceGroup \
    --environment prod
```

## Dapr APIs

### 🔗 Service-to-Service Invocation

Maakt veilige, directe service calls mogelijk.

**Gebruik:**
```http
GET http://localhost:3500/v1.0/invoke/myapp/method/mymethod
```

**Voordelen:**
- Service discovery
- Retry logic
- mTLS encryption
- Distributed tracing

---

### 💾 State Management

Beheert transacties en CRUD operaties.

**State opslaan:**
```http
POST http://localhost:3500/v1.0/state/mystatestore
Content-Type: application/json

[
  {
    "key": "order1",
    "value": {
      "orderId": "order1",
      "status": "pending"
    }
  }
]
```

**State ophalen:**
```http
GET http://localhost:3500/v1.0/state/mystatestore/order1
```

**Ondersteunde state stores:**
- Redis
- Cosmos DB
- Azure Table Storage
- SQL Server

---

### 📡 Pub/Sub

Faciliteert communicatie tussen container apps via message broker.

**Voor event-driven architecture.**

**Publish event:**
```http
POST http://localhost:3500/v1.0/publish/mypubsub/orders
Content-Type: application/json

{
  "orderId": "order1",
  "status": "completed"
}
```

**Subscribe in code:**
```csharp
app.MapPost("/orders", async (Order order) => {
    // Verwerk order
    return Results.Ok();
});
```

**Component configuratie:**
```yaml
apiVersion: dapr.io/v1alpha1
kind: Component
metadata:
  name: mypubsub
spec:
  type: pubsub.azure.servicebus
  metadata:
    - name: connectionString
      value: "<SERVICE_BUS_CONNECTION_STRING>"
```

**Ondersteunde pub/sub:**
- Azure Service Bus
- Azure Event Hubs
- Kafka
- Redis Streams

---

### 🔌 Bindings

Communiceer met externe systemen.

**Input binding** (trigger van externe bron):
```yaml
apiVersion: dapr.io/v1alpha1
kind: Component
metadata:
  name: myqueue
spec:
  type: bindings.azure.storagequeues
  metadata:
    - name: storageAccount
      value: "myaccount"
    - name: queue
      value: "myqueue"
    - name: storageAccessKey
      value: "<KEY>"
```

**Output binding** (verzenden naar externe systeem):
```http
POST http://localhost:3500/v1.0/bindings/myqueue
Content-Type: application/json

{
  "data": {
    "message": "Hello from Dapr!"
  },
  "operation": "create"
}
```

**Ondersteunde bindings:**
- Azure Storage Queues
- Azure Event Hubs
- Kafka
- Azure Service Bus
- Cron (scheduled triggers)

### 🎭 Actors

Ondersteunt schaalbare, message-driven units of work.

**Actor pattern:**
- Encapsulation van state en behavior
- Single-threaded execution
- Location transparency

**Actor aanmaken:**
```csharp
[Actor(TypeName = "OrderActor")]
public class OrderActor : Actor, IOrderActor
{
    public async Task ProcessOrder(string orderId)
    {
        await StateManager.SetStateAsync("order", orderId);
    }
}
```

**Actor aanroepen:**
```http
POST http://localhost:3500/v1.0/actors/OrderActor/order123/method/ProcessOrder
```

---

### 📊 Observability

Zendt tracing informatie naar Application Insights backend.

**Automatische tracing van:**
- Service-to-service calls
- State operations
- Pub/sub events
- Bindings

**Configuratie:**
```yaml
apiVersion: dapr.io/v1alpha1
kind: Configuration
metadata:
  name: appconfig
spec:
  tracing:
    samplingRate: "1"
    zipkin:
      endpointAddress: "http://zipkin:9411/api/v2/spans"
```

### 🔐 Secrets

Toegang tot secrets of referenties naar secure values in Dapr componenten.

**Secret referentie in component:**
```yaml
apiVersion: dapr.io/v1alpha1
kind: Component
metadata:
  name: statestore
spec:
  type: state.azure.cosmosdb
  metadata:
    - name: url
      value: "https://myaccount.documents.azure.com"
    - name: masterKey
      secretKeyRef:
        name: cosmosdb-key
        key: key
```

**Secret stores:**
- Azure Key Vault
- Kubernetes secrets
- Local file

## Dapr Components Configureren

### Component maken

```yaml
apiVersion: dapr.io/v1alpha1
kind: Component
metadata:
  name: mystatestore
spec:
  type: state.redis
  version: v1
  metadata:
    - name: redisHost
      value: "myredis:6379"
    - name: redisPassword
      secretKeyRef:
        name: redis-secret
        key: password
scopes:
  - myapp1
  - myapp2
```

**Scopes:** Beperkt component tot specifieke apps.

## CLI Commando's

```bash
# Dapr inschakelen
az containerapp create \
    --dapr-enabled \
    --dapr-app-id myapp \
    --dapr-app-port 3000 \
    --name MyApp \
    --resource-group MyResourceGroup \
    --environment prod

# Dapr component maken
az containerapp env dapr-component set \
    --name mycomponent \
    --environment prod \
    --resource-group MyResourceGroup \
    --dapr-component-name mystatestore \
    --yaml component.yaml

# Dapr components lijst
az containerapp env dapr-component list \
    --environment prod \
    --resource-group MyResourceGroup
```

## Best Practices

### 🎯 Application Scopes
Gebruik scopes om componenten te beperken tot relevante apps:
```yaml
scopes:
  - order-service
  - payment-service
```

### 🔐 Secrets Management
Gebruik altijd secret stores, nooit hardcoded secrets:
```yaml
secretKeyRef:
  name: my-secret
  key: connection-string
```

### 📈 Observability
Enable tracing voor debugging en monitoring:
```yaml
spec:
  tracing:
    samplingRate: "1"
```

### 🔄 Retry Policies
Configureer retry policies voor resilience:
```yaml
spec:
  resiliency:
    retries:
      retryPolicy:
        policy: exponential
        maxRetries: 3
```
