# ACR Tasks

ACR Tasks bieden geautomatiseerde build en deployment mogelijkheden binnen Azure Container Registry.

## Task Types

### ⚡ Quick Task

Eenmalige build en push operaties.

```bash
# Build en push image
az acr build \
    --registry myregistry \
    --image myimage:v1 \
    . # docker build, docker push

# Image draaien
az acr run \
    --registry myregistry \
    --cmd '$registryName/$repository/$imageName:$tag' \
    /dev/null
```

**Laatste parameter:** Source locatie (optioneel voor non-image building tasks)

---

### 🔄 Automatically Triggered Task

Automatisch getriggerd op basis van events.

#### Triggers

**CI on commit of pull-request:**
```bash
--commit-trigger-enabled true
--pull-request-trigger-enabled true
```

**CRON schedule** (⭐ voor OS/framework patching):
```bash
--schedule "0 0 * * *" # Dagelijks om middernacht
```

#### Task maken

```bash
# CI Task voor Git repository
az acr task create \
    --name ciTask \
    --registry myregistry \
    --image myimage:{{.Run.ID}} \
    --context https://github.com/myuser/myrepo.git \
    --file Dockerfile \
    --git-access-token $GIT_ACCESS_TOKEN

# Command Task
az acr task create \
    --name cmdTask \
    --registry myregistry \
    --cmd mcr.microsoft.com/hello-world \
    --context /dev/null

# Task handmatig uitvoeren
az acr task run --name mytask --registry myregistry
```

---

### 📋 Multi-step Task

Granulaire controle met build, push, when, cmd gedefinieerd als steps.

⚠️ **Let op:** `--file` wordt gebruikt voor zowel multi-step task als Dockerfile

```bash
# Multi-step task uitvoeren
az acr run \
    --file multi-step.yaml \
    https://github.com/Azure-Samples/acr-tasks.git

# Multi-step CI task maken
az acr task create \
    --file multi-step.yaml \
    --name ciTask \
    --registry myregistry \
    --image myimage:{{.Run.ID}} \
    --context https://github.com/myuser/myrepo.git \
    --git-access-token $GIT_ACCESS_TOKEN
```

## Platform Ondersteuning

```bash
--platform Linux # of Windows
```

**Linux:**
- Ondersteunt alle architecturen (bijv. Linux/arm)

**Windows:**
- Alleen amd64 (bijv. Windows/amd64)
- Architectuur is optioneel

---

## Voorbeeld Multi-step YAML

```yaml
version: v1.1.0
steps:
  - build: -t {{.Run.Registry}}/myimage:{{.Run.ID}} .
  - push: ["{{.Run.Registry}}/myimage:{{.Run.ID}}"]
  - cmd: {{.Run.Registry}}/myimage:{{.Run.ID}}
```
