# Container Apps Deployment

## Deployment Methodes

### 🚀 `az containerapp create`
Maakt een nieuwe container app in Azure met specifieke configuraties (CPU, geheugen, environment variables, etc).

**Best voor:** Volledige controle en specifieke configuraties

### ⚡ `az containerapp up`
Sneller en meer geautomatiseerd deployment proces.

**Best voor:** Development of testing, simpelheid en snelheid

---

## Wanneer Welke Methode?

**`az containerapp create`:**
- Anticipeer op meer controle of specifieke configuraties in de toekomst
- Producti workflows

**`az containerapp up`:**
- Simpelheid en snelheid zijn primaire zorgen
- Snelle prototypes
- Development/testing

## Setup Stappen

### 1. Azure CLI upgraden

```bash
az upgrade
```

### 2. Containerapp Extension toevoegen

```bash
az extension add --name containerapp --upgrade
```

### 3. Inloggen

```bash
az login
```

### 4. Providers registreren

```bash
# Voor hosting APIs
az provider register --namespace Microsoft.App

# Voor telemetry
az provider register --namespace Microsoft.OperationalInsights
```

### 5. Environment maken

```bash
az containerapp env create \
    --resource-group myResourceGroup \
    --name prod \
    --location eastus
```

## Deployment vanaf Repository

```bash
az containerapp up \
    --name MyAPI \
    --resource-group myResourceGroup \
    --location eastus \
    --environment prod \
    --context-path ./src \
    --repo myuser/myrepo \
    --ingress 'external'

# FQDN bekijken
az containerapp show \
    --name MyAPI \
    --resource-group myResourceGroup \
    --query properties.configuration.ingress.fqdn
```

**Ingress 'external':** Maakt applicatie toegankelijk vanaf internet

## Deployment vanaf Docker Image

### Publieke Docker Image

```bash
az containerapp up \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --environment prod \
    --image mcr.microsoft.com/azuredocs/containerapps-helloworld:latest \
    --target-port 80 \
    --ingress 'external' \
    --query properties.configuration.ingress.fqdn
```

### Docker Image vanuit ACR

```bash
az containerapp up \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --environment prod \
    --image myAcr.azurecr.io/myimage:latest \
    --registry-username myAcrUsername \
    --registry-password myAcrPassword \
    --target-port 80 \
    --ingress 'external'
```

## Deployment met Specifieke Configuratie

```bash
az containerapp create \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --environment prod \
    --image myimage:latest \
    --target-port 80 \
    --ingress external \
    --cpu 0.5 \
    --memory 1.0Gi \
    --min-replicas 1 \
    --max-replicas 10 \
    --env-vars "KEY=VALUE" "ANOTHER_KEY=ANOTHER_VALUE"
```

## Complete Deployment Workflow

```bash
# Variabelen
resourceGroup="myResourceGroup"
location="eastus"
environment="prod"
appName="MyContainerApp"
image="myregistry.azurecr.io/myapp:v1"

# 1. Resource group maken (als nodig)
az group create --name $resourceGroup --location $location

# 2. Environment maken
az containerapp env create \
    --name $environment \
    --resource-group $resourceGroup \
    --location $location

# 3. Container app deployen
az containerapp create \
    --name $appName \
    --resource-group $resourceGroup \
    --environment $environment \
    --image $image \
    --target-port 80 \
    --ingress external \
    --cpu 0.5 \
    --memory 1Gi \
    --min-replicas 1 \
    --max-replicas 5

# 4. URL ophalen
az containerapp show \
    --name $appName \
    --resource-group $resourceGroup \
    --query properties.configuration.ingress.fqdn \
    --output tsv
```

## Managed Identity voor ACR

```bash
# 1. Managed identity toewijzen
az containerapp identity assign \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --system-assigned

# 2. Identity ID ophalen
identityId=$(az containerapp show \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --query identity.principalId \
    --output tsv)

# 3. AcrPull role toewijzen
az role assignment create \
    --assignee $identityId \
    --role AcrPull \
    --scope /subscriptions/$subscriptionId/resourceGroups/$resourceGroup/providers/Microsoft.ContainerRegistry/registries/$registryName

# 4. Container app updaten om managed identity te gebruiken
az containerapp update \
    --name MyContainerApp \
    --resource-group myResourceGroup \
    --set properties.configuration.registries[0].server=$registryName.azurecr.io \
    --set properties.configuration.registries[0].identity=system
```
