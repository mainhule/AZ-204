# Docker Images Pushen en Draaien

## Image Pushen naar Registry

### Stap 1: Image pullen van Microsoft Registry

```bash
docker pull mcr.microsoft.com/hello-world
```

### Stap 2: Image taggen

```bash
docker tag mcr.microsoft.com/hello-world $registryName.azurecr.io/$repository/$imageName:$tag
```

**Formaat:**
```
<registry>.azurecr.io/<repository>/<image>:<tag>
```

### Stap 3: Image pushen

```bash
docker push $registryName.azurecr.io/$repository/$imageName:$tag
```

---

## Image Draaien vanuit Registry

### Optie 1: Docker run

```bash
docker run $registryName.azurecr.io/$repository/$imageName:$tag
```

### Optie 2: Azure ACR run

```bash
az acr run \
    --registry $registryName \
    --cmd '$registryName/$repository/$imageName:$tag' \
    /dev/null
```

---

## Images en Tags Bekijken

### Alle repositories lijst

```bash
az acr repository list \
    --name myregistry \
    --output table
```

### Tags van specifieke repository

```bash
az acr repository show-tags \
    --name myregistry \
    --repository myrepository \
    --output table
```

---

## Complete Workflow Voorbeeld

```bash
# Variabelen instellen
registryName="myregistry"
repository="myapp"
imageName="webapp"
tag="v1.0"

# 1. Image pullen
docker pull mcr.microsoft.com/dotnet/aspnet:6.0

# 2. Image taggen
docker tag mcr.microsoft.com/dotnet/aspnet:6.0 $registryName.azurecr.io/$repository/$imageName:$tag

# 3. Inloggen op registry
az acr login --name $registryName

# 4. Image pushen
docker push $registryName.azurecr.io/$repository/$imageName:$tag

# 5. Verifiëren
az acr repository show-tags --name $registryName --repository $repository/$imageName

# 6. Image draaien
docker run $registryName.azurecr.io/$repository/$imageName:$tag
```
