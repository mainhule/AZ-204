# Deployment

## Continuous Integration/Deployment

Built-in CI/CD met:
- Git (Azure DevOps, third-party, local)
- FTP
- Container registries (ACR, third-party)

## Deployment Stappen (Quick)

1. **Resource group maken**
   ```bash
   az group create --name MyResourceGroup --location eastus
   ```

2. **App Service Plan maken**
   ```bash
   az appservice plan create --name MyPlan --resource-group MyResourceGroup --location eastus
   ```

3. **Web app maken**
   ```bash
   az webapp create --name MyApp --plan MyPlan --runtime "DOTNET|6.0" --resource-group MyResourceGroup
   ```

4. **(Optioneel) Managed Identity voor ACR configureren**
   ```bash
   # Managed identity toewijzen aan web app
   az webapp identity assign --name MyApp --resource-group MyResourceGroup
   
   # AcrPull role toewijzen
   az role assignment create --assignee $principalId --scope $registry_resource_id --role "AcrPull"
   
   # Config instellen voor system identity
   az webapp config set --generic-configurations '{"acrUseManagedIdentityCreds":true}' --name MyApp --resource-group MyResourceGroup
   
   # OF voor user identity
   az webapp config set --generic-configurations '{"acrUserManagedIdentityID":"$principalId"}' --name MyApp --resource-group MyResourceGroup
   ```

5. **(Optioneel) Deployment slot maken (Standard+)**
   ```bash
   az webapp deployment slot create --name MyApp --slot staging --resource-group MyResourceGroup
   ```

6. **App deployen** (voeg `--slot staging` toe voor deployment slot)

   **Via Git:**
   ```bash
   az webapp deployment source config \
       --name MyApp \
       --repo-url $gitrepo \
       --branch master \
       --manual-integration \
       --resource-group MyResourceGroup
   ```

   **Via Docker:**
   ```bash
   az webapp config container set \
       --name MyApp \
       --docker-custom-image-name <docker-hub-repo>/<image> \
       --resource-group MyResourceGroup
   ```

   **Via Docker Compose:**
   ```bash
   # Skip stap 3, gebruik dit in plaats daarvan
   az webapp create \
       --name MyApp \
       --resource-group MyResourceGroup \
       --plan MyPlan \
       --multicontainer-config-type compose \
       --multicontainer-config-file $dockerComposeFile
   ```

   **Via lokale ZIP:**
   ```bash
   az webapp deploy --src-path "path/to/zip" --name MyApp --resource-group MyResourceGroup
   ```

   **Via remote ZIP:**
   ```bash
   az webapp deploy --src-url "<url>" --name MyApp --resource-group MyResourceGroup
   ```

7. **(Optioneel) Settings instellen**
   ```bash
   az webapp config appsettings set \
       --settings DEPLOYMENT_BRANCH='main' SCM_DO_BUILD_DURING_DEPLOYMENT=true \
       --name MyApp \
       --resource-group MyResourceGroup
   ```

8. **(Optioneel) Slots swappen**
   ```bash
   az webapp deployment slot swap --slot staging --name MyApp --resource-group MyResourceGroup
   ```

## Deployment Types

### 📦 Git Deployment

```bash
az webapp deployment source config \
    --name MyApp \
    --repo-url https://github.com/Azure-Samples/dotnet-core-sample \
    --branch master \
    --manual-integration \
    --resource-group MyResourceGroup

# Deployment branch wijzigen naar "main"
az webapp config appsettings set \
    --settings DEPLOYMENT_BRANCH='main' \
    --name MyApp \
    --resource-group MyResourceGroup
```

### 🎭 Staging Deployment

Gebruikt om file locking te voorkomen. Vereist Standard tier.

```bash
# Plan upgraden naar Standard
az appservice plan update --name MyPlan --sku S1 --resource-group MyResourceGroup

# Deployment slot maken
az webapp deployment slot create --name MyApp --slot staging --resource-group MyResourceGroup

# Deployen naar Staging
az webapp deployment source config \
    --name MyApp \
    --slot staging \
    --repo-url $gitrepo \
    --branch master \
    --manual-integration \
    --resource-group MyResourceGroup

# Staging slot swappen naar productie
az webapp deployment slot swap --slot staging --name MyApp --resource-group MyResourceGroup
```

### 🐳 Docker Deployment

```bash
# (Optioneel) Managed identity gebruiken
## System-assigned managed identity inschakelen
az webapp identity assign --name MyApp --resource-group MyResourceGroup

## Permission geven voor ACR toegang
az role assignment create --assignee $principalId --scope $registry_resource_id --role "AcrPull"

## Configureren om managed identity te gebruiken
az webapp config set \
    --generic-configurations '{"acrUseManagedIdentityCreds": true}' \
    --name MyApp \
    --resource-group MyResourceGroup

# Docker image deployen
az webapp config container set \
    --name MyApp \
    --docker-custom-image-name <docker-hub-repo>/<image> \
    --resource-group MyResourceGroup

# Voor private registry
az webapp config container set \
    --name MyApp \
    --docker-custom-image-name <private-repo>/<image> \
    --docker-registry-server-url <private-repo-url> \
    --docker-registry-server-user <username> \
    --docker-registry-server-password <password> \
    --resource-group MyResourceGroup
```

### 🎼 Docker Compose Deployment

```bash
# Webapp maken met Docker Compose
az webapp create \
    --name wordpressApp \
    --resource-group MyResourceGroup \
    --plan MyPlan \
    --multicontainer-config-type compose \
    --multicontainer-config-file docker-compose-wordpress.yml

# Database setup (voorbeeld met MySQL)
az mysql server create \
    --resource-group MyResourceGroup \
    --name wordpressDb \
    --location eastus \
    --admin-user adminuser \
    --admin-password letmein \
    --sku-name B_Gen5_1 \
    --version 5.7

az mysql db create \
    --resource-group MyResourceGroup \
    --server-name wordpressDb \
    --name wordpress

# App settings voor WordPress
az webapp config appsettings set \
    --settings \
        WORDPRESS_DB_HOST="wordpressDb.mysql.database.azure.com" \
        WORDPRESS_DB_USER="adminuser" \
        WORDPRESS_DB_PASSWORD="letmein" \
        WORDPRESS_DB_NAME="wordpress" \
        MYSQL_SSL_CA="BaltimoreCyberTrustroot.crt.pem" \
    --name wordpressApp \
    --resource-group MyResourceGroup
```

### 📁 ZIP Archive Deployment

Gebruikt dezelfde Kudu service als continuous integration-based deployments.

```bash
# Lokale ZIP
az webapp deploy \
    --src-path "path/to/zip" \
    --name MyApp \
    --resource-group MyResourceGroup

# Remote ZIP
az webapp deploy \
    --src-url "https://storage.blob.core.windows.net/container/myapp.zip?sv=2021-10-01&sig=..." \
    --name MyApp \
    --resource-group MyResourceGroup

# (Optioneel) Build automation inschakelen
az webapp config appsettings set \
    --settings SCM_DO_BUILD_DURING_DEPLOYMENT=true \
    --name MyApp \
    --resource-group MyResourceGroup
```

## ARM Templates

In JSON formaat.

### ARM template maken

```bash
# Van resource group
az group export --name MyResourceGroup

# Van specifieke deployment
az deployment group export --resource-group MyResourceGroup --name MyDeployment
```

### Deployment maken van ARM template

```bash
az deployment group create \
    --resource-group MyResourceGroup \
    --template-file template.json
```

## CLI Commando's Overzicht

```bash
# Web app maken
az webapp create --name MyApp --plan MyPlan --resource-group MyResourceGroup

# Deployment configureren
az webapp deployment source config --name MyApp --repo-url $gitrepo --branch master --manual-integration --resource-group MyResourceGroup

# Deployment slot maken
az webapp deployment slot create --name MyApp --slot staging --resource-group MyResourceGroup

# Slots swappen
az webapp deployment slot swap --slot staging --name MyApp --resource-group MyResourceGroup

# ZIP deployen
az webapp deploy --src-path "path/to/zip" --name MyApp --resource-group MyResourceGroup
```
