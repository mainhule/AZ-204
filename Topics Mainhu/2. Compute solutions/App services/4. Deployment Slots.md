# Deployment Slots

**Vereist: Standard+ tier**

Alle slots voor een web app delen hetzelfde deployment plan en dezelfde virtual machines. Ze hebben wel verschillende hostnamen.

## Best Practices

Deploy naar staging, dan swap slots om instances op te warmen en downtime te elimineren.

## Wat wordt wel/niet geswapt?

### ✅ Swapped
Settings die het **gedrag** van de applicatie definiëren:
- Connection strings
- Authentication settings
- Public certificates
- Path mappings
- CDN
- Hybrid connections

### ❌ Niet Swapped
Settings die de **omgeving en security** van de applicatie definiëren:
- Publishing endpoints
- Custom domain names
- Non-public certificates en TLS/SSL settings
- Scale settings
- WebJobs schedulers
- IP restrictions
- Always On
- Diagnostic log settings
- CORS
- Virtual network integration
- Managed identities
- Settings die eindigen met `_EXTENSION_VERSION`

## Settings Swapping inschakelen

Om settings swapping mogelijk te maken:
```bash
# Voeg deze app setting toe aan elke slot met waarde 0 of false
WEBSITE_OVERRIDE_PRESERVE_DEFAULT_STICKY_SLOT_SETTINGS=0
```

**Let op:** Managed identities worden **nooit** geswapt.

**Hybrid Connections:** Laat je Azure App veilig praten met je lokale server zonder firewall instellingen te wijzigen.

## Custom Deployment

`.deployment` bestand:

```txt
command = deploy.cmd # Script uitvoeren voor deployment
# project = WebProject/WebProject.csproj
```

## Production Traffic Handmatig Routeren

Gebruik `x-ms-routing-name=`:
- `self` voor production slot
- `staging` voor staging slot

Voorbeeld:
```html
<a href="<webappname>.azurewebsites.net/?x-ms-routing-name=self">Terug naar productie</a>
<a href="<webappname>.azurewebsites.net/?x-ms-routing-name=staging">Terug naar staging</a>
```

⏺️ **Standaard:** Alle requests gaan naar productie. Traffic kan worden gesplitst; nieuwe slots starten op 0% (geen random transfers naar andere slots).

## CLI Commando's

```bash
# Deployment slot maken
az webapp deployment slot create --name MyApp --slot staging --resource-group MyResourceGroup

# Slots swappen
az webapp deployment slot swap --slot staging --name MyApp --resource-group MyResourceGroup

# Deployment vanaf Git configureren
az webapp deployment source config --name MyApp --repo-url $gitrepo --branch master --manual-integration --resource-group MyResourceGroup
```
