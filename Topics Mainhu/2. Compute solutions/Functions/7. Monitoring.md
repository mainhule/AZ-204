# Monitoring

## Application Insights

### Automatische Integratie

✅ **Standaard ingeschakeld** voor nieuwe functions (gemaakt in dezelfde of dichtstbijzijnde regio)

⚠️ Moet mogelijk **handmatig ingeschakeld** worden voor oude functions

### Data verzenden

Om data te verzenden heb je de key nodig genaamd `APPINSIGHTS_INSTRUMENTATIONKEY`.

✅ Gebruik `ILogger` (niet `TelemetryClient`!)

✅ Azure Functions gebruiken **Adaptive sampling**

## Configuratie

Application Insights worden geconfigureerd in **host.json**:
- `logging.applicationInsights`
- `aggregator`

### SQL Query inschakelen

```json
{
  "logging": {
    "applicationInsights": {
      "enableDependencyTracking": true,
      "dependencyTrackingOptions": {
        "enableSqlCommandTextInstrumentation": true
      }
    }
  }
}
```

### Scale Controller Logging

**Verbose logging inschakelen:**
```bash
az functionapp config appsettings set \
    --settings SCALE_CONTROLLER_LOGGING_ENABLED=AppInsights:Verbose \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

**Logging uitschakelen:**
```bash
az functionapp config appsettings delete \
    --setting-names SCALE_CONTROLLER_LOGGING_ENABLED \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

## Log Categories

Identificeren welk deel van het systeem of user code de log heeft gegenereerd.

### 🔧 Function.<YOUR_FUNCTION_NAME>
Relateert aan:
- Dependency data
- Custom metrics en events
- Trace logs voor function runs
- User-generated logs

### 📊 Host.Aggregator
Biedt geaggregeerde counts en averages van function invocations.

### ✅ Host.Results
Registreert het succes of falen van functies.

### 🔷 Microsoft
Reflecteert een .NET runtime component aangeroepen door de host.

### 👷 Worker
Logs gegenereerd door language worker processen voor non-.NET talen.

## High Volume Telemetry

Voor situaties met hoge volumes aan telemetry.

```json
{
  "version": "2.0",
  "logging": {
    "logLevel": {
      "default": "Warning",
      "Function": "Error",
      "Host.Aggregator": "Error",
      "Host.Results": "Information",
      "Function.Function1": "Information",
      "Function.Function1.User": "Error"
    },
    "applicationInsights": {
      "samplingSettings": {
        "isEnabled": true,
        "maxTelemetryItemsPerSecond": 1,
        "excludedTypes": "Exception"
      }
    }
  }
}
```

⚠️ **Let op:**  
Wees bewust van de `flushTimeout` (in aggregator) vertraging als je een andere waarde dan Information instelt.
