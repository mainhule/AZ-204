# Storage Considerations

## Belangrijke Storage Aspecten

⚠️ **Function code en configuratie bestanden** worden opgeslagen in Azure Files in de gekoppelde storage account. Het verwijderen van dit account resulteert in verlies van deze bestanden.

✅ Azure Functions vereist een Azure Storage account voor services zoals:
- Azure Blob Storage
- Azure Files
- Azure Queue Storage
- Azure Table Storage

✅ Storage accounts gebruikt door function apps moeten Blob, Queue, en Table storage ondersteunen.

✅ **Storage account moet in dezelfde regio** zijn als de function app voor performance optimalisatie.

✅ **Elke function app moet een aparte storage account** gebruiken voor beste performance.

✅ Azure Storage versleutelt alle data in een storage account at rest.

⚠️ Functions gebruiken een **host ID waarde** om een function app uniek te identificeren in opgeslagen artifacts. Host ID collisions kunnen voorkomen en moeten worden vermeden.
