# Configuratie

De volgende talen kunnen direct in Azure Portal worden gebruikt (geen externe editor nodig): `C# Script`, `JavaScript`, `Python`, `PowerShell`.

## Configuratie Bestanden Overzicht

### 📝 Application Settings
- Cloud-based environment variables
- Veilig opslaan van secrets (bijv. connection strings)
- Instelbaar via Portal/CLI/ARM
- Toegankelijk via `%VAR%` of `Environment.GetEnvironmentVariable()`

### 📋 function.json
- Per-function bindings configuratie (alleen script talen)
- Declareert triggers, inputs, outputs
- Refereert naar **Application Settings** op naam

### ⚙️ host.json
- App-wide runtime configuratie
- Controleert logging, timeouts, retries, en extension settings

### 💻 local.settings.json
- Alleen voor lokale development
- `"Values"` bootst **Application Settings** na
- Nooit deployen of committen (kan secrets bevatten)

## host.json

Belangrijke settings:

### Timeouts
```json
{
  "functionTimeout": "00:05:00"
}
```
- **Default:** 5 min voor Consumption, 30 min voor rest

### Logging
```json
{
  "logging": {
    "applicationInsights": {
      "samplingSettings": {
        "isEnabled": true
      }
    }
  }
}
```

### Aggregator
```json
{
  "aggregator": {
    "batchSize": 1000,
    "flushTimeout": "00:00:30"
  }
}
```
Specificeert hoeveel function invocations worden geaggregeerd bij het berekenen van metrics voor Application Insights.

### HTTP Extensions
```json
{
  "extensions": {
    "http": {
      "dynamicThrottlesEnabled": true
    }
  }
}
```
- **Default ingeschakeld** voor Consumption only
- Throttles bij hoog resource gebruik

### Blob Extensions
```json
{
  "extensions": {
    "blobs": {
      "maxDegreeOfParallelism": 8
    }
  }
}
```
Concurrent invocations toegestaan voor alle blob-triggered functions (min: 1, default: 8)

### Cosmos DB Extensions
```json
{
  "extensions": {
    "cosmosDB": {
      "connectionMode": "Gateway",
      "userAgentSuffix": "MyApp"
    }
  }
}
```
- **connectionMode:** _Gateway_ (default) of _Direct_
  - _Gateway_ is aan te raden voor _Consumption_ plan vanwege connections limit
  - _Direct_ heeft betere performance
- **userAgentSuffix:** Voegt string toe aan alle service requests van trigger/binding voor betere tracking in Azure Monitor

## function.json

Auto gegenereerd voor compiled languages.  
Voor scripting languages zoals `C# Script`, `Python`, moet je het config bestand zelf aanmaken.

### Belangrijke regels

✅ Voor triggers is de direction altijd `in`

✅ Input en output bindings gebruiken `in` en `out`, of `inout` in sommige gevallen

✅ `connection` verwijst naar een environment variable met de connection string. **Het bevat nooit het daadwerkelijke secret**. Definieer de connection string in `Application Settings`.

### Voorbeeld

```json
{
  "bindings": [
    {
      "type": "queueTrigger",
      "direction": "in",
      "name": "order",
      "queueName": "myqueue-items",
      "connection": "MY_STORAGE_ACCT_APP_SETTING"
    },
    {
      "type": "table",
      "direction": "out",
      "name": "$return",
      "tableName": "outTable",
      "connection": "MY_TABLE_STORAGE_ACCT_APP_SETTING"
    }
  ]
}
```

## Configuratie via CLI

### Function App Scale Limit

```bash
az resource update \
    --resource-type Microsoft.Web/sites \
    --resource-group MyResourceGroup \
    --name MyFunctionApp/config/web \
    --set properties.functionAppScaleLimit=10
```

Waarden:
- 0 of null voor onbeperkt
- Geldige waarde tussen 1 en app maximum (200 voor Consumption, 100 voor Premium)

### Application Settings

```bash
# Settings ophalen
az functionapp config appsettings list \
    --name MyFunctionApp \
    --resource-group MyResourceGroup

# Setting toevoegen of updaten
az functionapp config appsettings set \
    --settings CUSTOM_FUNCTION_APP_SETTING=12345 \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

## local.settings.json

Alleen voor lokale development.

```json
{
  "IsEncrypted": false,
  "Values": {
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "FUNCTIONS_WORKER_RUNTIME": "dotnet"
  },
  "Host": {
    "LocalHttpPort": 7071,
    "CORS": "*",
    "CORSCredentials": false
  },
  "ConnectionStrings": {
    "SQLConnectionString": "Value"
  }
}
```

### Properties

**IsEncrypted:**  
Wanneer true, worden alle waarden encrypted met een local machine key.

**Values:**  
Komen overeen met application settings in je function app in Azure.

**Host:**  
Customize de Functions host process
- `LocalHttpPort`: Poort nummer
- `CORS`: Ondersteunt wildcard waarde (*)
- `CORSCredentials`: Wanneer true, staat withCredentials requests toe

**ConnectionStrings:**  
Gebruikt door frameworks die connection strings halen uit ConnectionStrings sectie van een config file.
