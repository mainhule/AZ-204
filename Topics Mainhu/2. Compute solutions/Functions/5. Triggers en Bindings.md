# Triggers en Bindings

**Triggers** veroorzaken dat een functie draait. Een trigger definieert hoe een functie wordt aangeroepen en een functie moet precies één trigger hebben.

**Binding** aan een functie is een manier om declaratief een andere resource te verbinden aan de functie:
- **Input bindings** (lezen)
- **Output bindings** (schrijven)
- Of beide

Triggers en bindings moeten worden gedefinieerd in C# (ook ondersteund: Python, Java, TypeScript, PS)

## Wat kan niet?

❌ **Kan geen trigger zijn:** Table Storage

❌ **Kan geen input binding zijn:** Event Grid, Event Hubs, HTTP & webhooks, IoT Hub, Queue storage, SendGrid, Service Bus, Timer

❌ **Kan geen output binding zijn:** IoT Hub, Timer

✅ **Standaard beschikbaar** (anderen moeten als apart pakket geïnstalleerd worden): Timer, HTTP & webhooks

❌ **Niet ondersteund op Consumption plan** (vereist runtime-driven triggers): RabbitMQ, Kafka

## Triggers en Bindings Overzicht

### 🌐 HTTP Trigger
```csharp
[HttpTrigger(AuthorizationLevel.Function, "get", "post", Route = "blob/{name}")] 
HttpRequest req, string name
```

**Custom Route:**  
`Route = "products/{id}"` maakt functie toegankelijk op:  
`https://<APP_NAME>.azurewebsites.net/api/<FUNCTION_NAME>/products/{id}`

**Limieten:**
- Request length: 100 MB
- URL length: 4 KB
- Timeout: 230s (502 error)

---

### 📦 Blob Storage

**Trigger:**
```csharp
[BlobTrigger("container/{name}")] string myBlob, string name
```

**Input:**
```csharp
[Blob("container/{name}", FileAccess.Read)] Stream myBlob
[Blob("container/{name}.jpg", FileAccess.Read)] Stream myBlob // Wildcard: jpg bestand
```

**Output:**
```csharp
[Blob("container/{name}", FileAccess.Write)] Stream myBlob
[BlobOutput("test-samples-output/{name}-output.txt")] // return object
```

---

### 🗄️ Cosmos DB

**Trigger:**
```csharp
[CosmosDBTrigger(
    databaseName: "databaseName",
    containerName: "containerName",
    Connection = "CosmosDBConnectionSetting",
    LeaseContainerName = "leases",
    CreateLeaseContainerIfNotExists = true)]
IReadOnlyList<ToDoItem> input
```

**Input:**
```csharp
[CosmosDB(
    databaseName:"myDb", 
    collectionName:"collection", 
    Id = "{id}", 
    PartitionKey ="{partitionKey}")]
dynamic document
```

**Output:**
```csharp
[CosmosDB(
    databaseName:"myDb", 
    collectionName:"collection", 
    CreateIfNotExists = true)]
out dynamic document
```

### 📡 Event Grid

**Trigger:**
```csharp
[EventGridTrigger] EventGridEvent ev // ev.Data
```

❌ Geen Input binding

**Output:**
```csharp
// Return
[return: EventGrid(
    TopicEndpointUri = "EventGridTopicUriAppSetting", 
    TopicKeySetting = "EventGridTopicKeyAppSetting")]
// return new EventGridEvent(...) of new CloudEvent(...)

// Out parameter
[EventGrid(...)] out eventGridEvent

// Batch processing
[EventGrid(...)] IAsyncCollector<EventGridEvent> outputEvents
// outputEvents.AddAsync(myEvent)
```

### 🎯 Event Hubs

```csharp
EventData[] events
```

```csharp
[return: EventHub("outputEventHubMessage", Connection = "EventHubConnectionAppSetting")]

```

### 📨 Queue Storage

**Trigger:**
```csharp

```

### ⏰ Timer

**Trigger:**
```csharp
[TimerTrigger("0 */5 * * * *")] TimerInfo myTimer
```

❌ Geen Input/Output binding

### Cron Expressie Formaat

**6-field format:** `{second} {minute} {hour} {day} {month} {day-of-week}`  
**5-field format:** Laat `{second}` weg, start met `{minute}`

**Syntaxis:**
- Specifieke waarde: `5` (exact 5e minuut)
- Lijst: `5,10` (5e en 10e minuut)
- Range: `9-17` (van 9 tot 17)
- Step: `*/5` (elke 5 eenheden)
- Any waarde: `*` (elke eenheid)

**Let op:**
- Day of week: MON is 1, Sunday is 0 of 7
- Day en Month starten vanaf 1

**Voorbeelden:**
- `*/5 * * * *`: Elke 5 minuten
- `0 9-17 * * MON-FRI`: 9 AM tot 5 PM op weekdagen

**⚠️ Opmerking:**  
`WEBSITE_TIME_ZONE` en `TZ` worden momenteel niet ondersteund op Linux Consumption plan.  
RunOnStartup wordt niet aanbevolen voor productie (verstoort schedule).
