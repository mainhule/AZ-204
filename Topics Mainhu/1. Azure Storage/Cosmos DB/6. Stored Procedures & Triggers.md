# ⚙️ Azure Cosmos DB - Stored Procedures, Triggers & UDFs

## 📖 Wat is Server-side Programming?

Azure Cosmos DB ondersteunt **server-side programmering** in **JavaScript**. Dit stelt je in staat om logica uit te voeren binnen de database zelf, dicht bij de data.

### 🎯 Drie Types

```
┌────────────────────────────────────────────┐
│      Server-side Programming Types         │
├────────────────────────────────────────────┤
│  1. Stored Procedures  📝 Business logic   │
│  2. Triggers           ⚡ Pre/Post actions │
│  3. User-Defined       🔧 Custom functions │
│     Functions (UDFs)                       │
└────────────────────────────────────────────┘
```

**💡 Belangrijke eigenschappen:**
- Geschreven in **JavaScript**
- Uitgevoerd **binnen de database engine**
- Ondersteunen **ACID transacties** binnen één partition
- Moeten worden **geregistreerd** voordat ze kunnen worden aangeroepen
- Hebben een **execution time limit** (5 seconden voor server-side scripting)

---

## 📝 1. Stored Procedures

**💡 Omschrijving:**  
JavaScript functies die CRUD operaties en queries uitvoeren. Ze draaien binnen een **transactie** en hebben toegang tot de container context.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Taal** | JavaScript |
| **Scope** | Single partition (transactional) |
| **Time limit** | 5 seconden execution time |
| **Return value** | Boolean success indicator |
| **Transactions** | ✅ ACID binnen partition |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Batch operations** (insert/update/delete meerdere items)
- **Transactional operations** (all-or-nothing semantics)
- **Complex business logic** die data transformatie vereist
- **Reducing round-trips** (logica bij de data)
- **Consistency guarantees** binnen één partition

---

### 🔧 Context API

Stored procedures hebben toegang tot een **context object** met twee belangrijke properties:

```javascript
var context = getContext();

// 1. Collection - voor CRUD operaties
var container = context.getCollection();
// Methods:
// - createDocument(link, doc, callback)
// - queryDocuments(link, query, callback)
// - replaceDocument(docLink, doc, callback)
// - deleteDocument(docLink, callback)
// - getSelfLink()

// 2. Response - voor response body
var response = context.getResponse();
// Methods:
// - getBody()
// - setBody(value)
```

---

### 💻 Stored Procedure Voorbeelden

#### Voorbeeld 1: Hello World

```javascript
// Eenvoudigste stored procedure
var helloWorldStoredProc = {
    id: "helloWorld",
    serverScript: function () {
        var context = getContext();
        var response = context.getResponse();

        response.setBody("Hello, World from Cosmos DB!");
    }
};
```

#### Voorbeeld 2: Create Document

```javascript
var createDocumentStoredProc = {
    id: "createMyDocument",
    body: function createMyDocument(documentToCreate) {
        var context = getContext();
        var container = context.getCollection();
        var containerLink = container.getSelfLink();

        // Async operation met callback
        var accepted = container.createDocument(
            containerLink,
            documentToCreate,
            function (err, documentCreated) {
                if (err) throw new Error('Error: ' + err.message);
                
                // Set response body naar ID van nieuwe document
                context.getResponse().setBody(documentCreated.id);
            }
        );

        // Als operation niet accepted is, return
        if (!accepted) return;
    }
};
```

#### Voorbeeld 3: Batch Insert

```javascript
var bulkInsertStoredProc = {
    id: "bulkInsert",
    body: function bulkInsert(docs) {
        var context = getContext();
        var container = context.getCollection();
        var containerLink = container.getSelfLink();
        var response = context.getResponse();
        var docsLength = docs.length;
        var count = 0;

        // Validation
        if (!docs) throw new Error("Document array is undefined or null");
        if (docs.length == 0) {
            response.setBody(0);
            return;
        }

        // Recursive function om documents te inserten
        function createDoc(index) {
            // Base case
            if (index >= docsLength) {
                response.setBody(count);
                return;
            }

            // Create document
            var accepted = container.createDocument(
                containerLink,
                docs[index],
                function (err, doc) {
                    if (err) throw new Error('Error: ' + err.message);
                    count++;
                    createDoc(index + 1); // Recursive call
                }
            );

            // Time limit check
            if (!accepted) {
                // Execution time limit bereikt
                response.setBody(count);
            }
        }

        createDoc(0); // Start recursion
    }
};
```

#### Voorbeeld 4: Update with Business Logic

```javascript
var updateOrderStatusProc = {
    id: "updateOrderStatus",
    body: function updateOrderStatus(orderId, newStatus) {
        var context = getContext();
        var container = context.getCollection();
        var response = context.getResponse();

        // Query om order te vinden
        var filterQuery = `SELECT * FROM c WHERE c.id = "${orderId}"`;
        
        var accepted = container.queryDocuments(
            container.getSelfLink(),
            filterQuery,
            function (err, documents) {
                if (err) throw new Error('Query error: ' + err.message);
                if (documents.length == 0) throw new Error('Order not found');

                var order = documents[0];

                // Business logic: Validate status transition
                var validTransitions = {
                    'pending': ['processing', 'cancelled'],
                    'processing': ['shipped', 'cancelled'],
                    'shipped': ['delivered'],
                    'delivered': [],
                    'cancelled': []
                };

                if (!validTransitions[order.status].includes(newStatus)) {
                    throw new Error(`Invalid status transition from ${order.status} to ${newStatus}`);
                }

                // Update status
                order.status = newStatus;
                order.lastModified = new Date().toISOString();

                // Replace document
                container.replaceDocument(
                    order._self,
                    order,
                    function (err, replaced) {
                        if (err) throw new Error('Replace error: ' + err.message);
                        response.setBody(replaced);
                    }
                );
            }
        );

        if (!accepted) throw new Error('Query not accepted');
    }
};
```

### ⚠️ Belangrijke Opmerkingen

**Parameters zijn altijd strings:**
```javascript
function myStoredProc(arr) {
    // Parameters worden als string geparsed!
    if (typeof arr === "string") {
        arr = JSON.parse(arr);
    }

    arr.forEach(function(item) {
        // Process item
    });
}
```

**Boolean return value:**
```javascript
var accepted = container.createDocument(...);
// accepted = true: Operation gestart
// accepted = false: Time limit bereikt, execution stopt
```

**Continuation tokens:**
```javascript
// Voor lange operaties gebruik continuation tokens
var accepted = container.queryDocuments(
    link,
    query,
    { continuation: token },
    callback
);
```

## ⚡ 2. Triggers

**💡 Omschrijving:**  
Functies die **automatisch** worden uitgevoerd **vóór** (pre-trigger) of **na** (post-trigger) een item operatie.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Types** | Pre-trigger, Post-trigger |
| **Automatisch?** | ❌ Nee, moet expliciet worden gespecificeerd per request |
| **Scope** | Single item operation |
| **Use case** | Validation, logging, metadata updates |

---

### 🔹 Pre-triggers

**💡 Functie:** Uitgevoerd **VOOR** een item wordt gemodificeerd. Kan item properties valideren of wijzigen.

**⚠️ Belangrijk:**
- **Geen input parameters** toegestaan
- Heeft toegang tot `request.getBody()` en `request.setBody()`
- Kan item aanpassen voordat het wordt opgeslagen

#### Voorbeeld: Timestamp Validator

```javascript
function validateToDoItemTimestamp() {
    var context = getContext();
    var request = context.getRequest();

    // Item dat wordt aangemaakt
    var itemToCreate = request.getBody();

    // Validatie: Check of timestamp property bestaat
    if (!("timestamp" in itemToCreate)) {
        var ts = new Date();
        itemToCreate["timestamp"] = ts.getTime();
    }

    // Update het item
    request.setBody(itemToCreate);
}
```

#### Voorbeeld: Data Validation

```javascript
function validatePrice() {
    var context = getContext();
    var request = context.getRequest();
    var item = request.getBody();

    // Business rule: Price moet positief zijn
    if (item.price && item.price < 0) {
        throw new Error("Price cannot be negative");
    }

    // Auto-calculate discount price
    if (item.price && item.discountPercentage) {
        item.discountedPrice = item.price * (1 - item.discountPercentage / 100);
        request.setBody(item);
    }
}
```

---

### 🔹 Post-triggers

**💡 Functie:** Uitgevoerd **NA** een item is gemodificeerd. Kan metadata updaten of logging uitvoeren.

**⚠️ Belangrijk:**
- Heeft toegang tot het **gecreëerde/geüpdatete** item via `response.getBody()`
- Draait binnen **dezelfde transactie** als de operatie
- Kan andere items updaten (bijv. metadata)

#### Voorbeeld: Update Metadata

```javascript
function updateMetadata() {
    var context = getContext();
    var container = context.getCollection();
    var response = context.getResponse();

    // Item dat net is aangemaakt
    var createdItem = response.getBody();

    // Query metadata document
    var filterQuery = 'SELECT * FROM root r WHERE r.id = "_metadata"';
    
    var accepted = container.queryDocuments(
        container.getSelfLink(),
        filterQuery,
        function (err, items) {
            if (err) throw new Error("Error: " + err.message);
            if (items.length != 1) throw new Error("Unable to find metadata document");

            var metadataItem = items[0];

            // Update metadata counters
            metadataItem.createdItems = (metadataItem.createdItems || 0) + 1;
            metadataItem.createdNames = (metadataItem.createdNames || "") + " " + createdItem.id;
            metadataItem.lastModified = new Date().toISOString();

            // Replace metadata document
            var accepted = container.replaceDocument(
                metadataItem._self,
                metadataItem,
                function (err, replaced) {
                    if (err) throw new Error("Unable to update metadata");
                }
            );

            if (!accepted) throw new Error("Unable to update metadata");
        }
    );

    if (!accepted) throw new Error("Unable to query metadata");
}
```

#### Voorbeeld: Audit Logging

```javascript
function auditLog() {
    var context = getContext();
    var container = context.getCollection();
    var response = context.getResponse();
    var createdItem = response.getBody();

    // Create audit log entry
    var auditEntry = {
        id: "audit-" + new Date().getTime(),
        itemId: createdItem.id,
        operation: "CREATE",
        timestamp: new Date().toISOString(),
        user: createdItem.createdBy || "system"
    };

    container.createDocument(
        container.getSelfLink(),
        auditEntry,
        function (err, doc) {
            if (err) throw new Error("Audit logging failed: " + err.message);
        }
    );
}
```

## 🔧 3. User-Defined Functions (UDFs)

**💡 Omschrijving:**  
Custom functies die gebruikt kunnen worden **binnen queries** voor berekeningen of transformaties.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Gebruik** | Binnen SQL queries (SELECT, WHERE, etc.) |
| **Input** | Function parameters |
| **Output** | Scalar value (number, string, boolean, etc.) |
| **Use case** | Complex calculations, data transformations |

---

### 💻 UDF Voorbeelden

#### Voorbeeld 1: Tax Calculation

```javascript
function tax(income) {
    // Validation
    if (income == undefined) throw new Error("Income is required");

    // Progressive tax brackets
    if (income < 1000) {
        return income * 0.1;
    } else if (income < 10000) {
        return income * 0.2;
    } else {
        return income * 0.4;
    }
}
```

**Gebruik in query:**
```sql
SELECT 
    c.id,
    c.income,
    udf.tax(c.income) AS taxAmount,
    c.income - udf.tax(c.income) AS netIncome
FROM c
WHERE udf.tax(c.income) > 500
```

#### Voorbeeld 2: String Manipulation

```javascript
function formatName(firstName, lastName) {
    if (!firstName || !lastName) return "Unknown";
    return lastName.toUpperCase() + ", " + firstName;
}
```

**Gebruik in query:**
```sql
SELECT 
    udf.formatName(c.firstName, c.lastName) AS fullName,
    c.email
FROM c
ORDER BY udf.formatName(c.firstName, c.lastName)
```

#### Voorbeeld 3: Distance Calculation

```javascript
function calculateDistance(lat1, lon1, lat2, lon2) {
    // Haversine formula voor distance tussen twee coordinaten
    var R = 6371; // Earth radius in km
    var dLat = toRad(lat2 - lat1);
    var dLon = toRad(lon2 - lon1);
    
    var a = Math.sin(dLat/2) * Math.sin(dLat/2) +
            Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) *
            Math.sin(dLon/2) * Math.sin(dLon/2);
    
    var c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
    var distance = R * c;
    
    return distance;
    
    function toRad(degrees) {
        return degrees * Math.PI / 180;
    }
}
```

**Gebruik in query:**
```sql
SELECT 
    c.name,
    c.address.city,
    udf.calculateDistance(52.3676, 4.9041, c.lat, c.lon) AS distanceFromAmsterdam
FROM c
WHERE udf.calculateDistance(52.3676, 4.9041, c.lat, c.lon) < 50
ORDER BY distanceFromAmsterdam
```

## 📝 Registratie & Aanroep

### C# SDK

```csharp
using Microsoft.Azure.Cosmos;
using Microsoft.Azure.Cosmos.Scripts;

var cosmosClient = new CosmosClient("<endpoint>", "<key>");
var container = cosmosClient.GetContainer("database", "container");

// ========================================
// 1. Stored Procedure Registratie
// ========================================

string spBody = File.ReadAllText("createDocument.js");

StoredProcedureProperties spProperties = new StoredProcedureProperties
{
    Id = "createMyDocument",
    Body = spBody
};

StoredProcedureResponse spResponse = await container.Scripts.CreateStoredProcedureAsync(spProperties);
Console.WriteLine($"Created stored procedure: {spResponse.Resource.Id}");

// ========================================
// 2. Stored Procedure Aanroepen
// ========================================

dynamic[] items = new[]
{
    new { id = "1", category = "Personal", name = "Groceries" },
    new { id = "2", category = "Personal", name = "Gas" }
};

// Parameters: partition key + arguments
StoredProcedureExecuteResponse<string> executeResponse = await container.Scripts.ExecuteStoredProcedureAsync<string>(
    storedProcedureId: "bulkInsert",
    partitionKey: new PartitionKey("Personal"),
    parameters: new dynamic[] { items }
);

Console.WriteLine($"Items created: {executeResponse.Resource}");
Console.WriteLine($"RU charge: {executeResponse.RequestCharge}");

// ========================================
// 3. Pre-trigger Registratie
// ========================================

string preTriggerBody = File.ReadAllText("validateTimestamp.js");

TriggerProperties preTriggerProperties = new TriggerProperties
{
    Id = "validateTimestamp",
    Body = preTriggerBody,
    TriggerOperation = TriggerOperation.Create, // Create, Replace, Delete, All
    TriggerType = TriggerType.Pre
};

await container.Scripts.CreateTriggerAsync(preTriggerProperties);

// ========================================
// 4. Pre-trigger Gebruiken
// ========================================

dynamic newItem = new { id = "3", category = "Personal", name = "Rent" };

ItemResponse<dynamic> createResponse = await container.CreateItemAsync(
    item: newItem,
    partitionKey: new PartitionKey("Personal"),
    requestOptions: new ItemRequestOptions
    {
        PreTriggers = new List<string> { "validateTimestamp" }
    }
);

// ========================================
// 5. Post-trigger Registratie
// ========================================

string postTriggerBody = File.ReadAllText("updateMetadata.js");

TriggerProperties postTriggerProperties = new TriggerProperties
{
    Id = "updateMetadata",
    Body = postTriggerBody,
    TriggerOperation = TriggerOperation.Create,
    TriggerType = TriggerType.Post
};

await container.Scripts.CreateTriggerAsync(postTriggerProperties);

// ========================================
// 6. Post-trigger Gebruiken
// ========================================

ItemResponse<dynamic> createWithPostTrigger = await container.CreateItemAsync(
    item: newItem,
    partitionKey: new PartitionKey("Personal"),
    requestOptions: new ItemRequestOptions
    {
        PostTriggers = new List<string> { "updateMetadata" }
    }
);

// ========================================
// 7. UDF Registratie
// ========================================

string udfBody = File.ReadAllText("tax.js");

UserDefinedFunctionProperties udfProperties = new UserDefinedFunctionProperties
{
    Id = "tax",
    Body = udfBody
};

await container.Scripts.CreateUserDefinedFunctionAsync(udfProperties);

// ========================================
// 8. UDF Gebruiken in Query
// ========================================

var query = new QueryDefinition(
    "SELECT c.id, c.income, udf.tax(c.income) AS taxAmount FROM c WHERE udf.tax(c.income) > @minTax"
).WithParameter("@minTax", 500);

FeedIterator<dynamic> iterator = container.GetItemQueryIterator<dynamic>(query);

while (iterator.HasMoreResults)
{
    FeedResponse<dynamic> response = await iterator.ReadNextAsync();
    foreach (var item in response)
    {
        Console.WriteLine($"ID: {item.id}, Income: {item.income}, Tax: {item.taxAmount}");
    }
}

// ========================================
// 9. List & Delete Scripts
// ========================================

// List stored procedures
FeedIterator<StoredProcedureProperties> spIterator = container.Scripts.GetStoredProcedureQueryIterator<StoredProcedureProperties>();
while (spIterator.HasMoreResults)
{
    foreach (var sp in await spIterator.ReadNextAsync())
    {
        Console.WriteLine($"Stored Procedure: {sp.Id}");
    }
}

// Delete stored procedure
await container.Scripts.DeleteStoredProcedureAsync("createMyDocument");

// Delete trigger
await container.Scripts.DeleteTriggerAsync("validateTimestamp");

// Delete UDF
await container.Scripts.DeleteUserDefinedFunctionAsync("tax");
```

## ⚠️ Limitations & Belangrijke Opmerkingen

### 🕐 Time Limits
- **5 seconden** maximum execution time
- Bij overschrijding: Operation retourneert `false`
- Gebruik **continuation tokens** voor lange operaties

### 🔒 Transactions
- **ACID garanties** alleen binnen **één partition**
- Cross-partition operations zijn **NIET transactional**

### 🚫 Triggers zijn Niet Automatisch
```csharp
// ❌ Trigger wordt NIET automatisch uitgevoerd
await container.CreateItemAsync(item);

// ✅ Trigger moet expliciet worden gespecificeerd
await container.CreateItemAsync(
    item,
    requestOptions: new ItemRequestOptions { 
        PreTriggers = new List<string> { "myTrigger" } 
    }
);
```

### 📦 Parameters als Strings
```javascript
// Stored procedure ontvangt ALTIJD strings
function myStoredProc(jsonArray) {
    // Parse if needed
    if (typeof jsonArray === "string") {
        jsonArray = JSON.parse(jsonArray);
    }
    // Now use as array
}
```

## 🏆 Best Practices

### ✅ Do's

| Praktijk | Reden |
|----------|-------|
| **Gebruik stored procedures voor batch operations** | Vermindert network round-trips |
| **Valideer input in pre-triggers** | Catch errors before write |
| **Keep UDFs simple** | Complex logic verhoogt query RU cost |
| **Test execution time** | Monitor 5 seconden limiet |
| **Use continuation tokens voor lange operaties** | Voorkomt timeouts |
| **Error handling in callbacks** | Proper error propagation |

### ❌ Don'ts

| Anti-pattern | Waarom niet? |
|--------------|---------------|
| **Cross-partition transacties** | Niet ondersteund |
| **Heavy computation in UDFs** | Verhoogt query costs dramatisch |
| **Veronderstellen triggers zijn automatic** | Moeten expliciet worden aangeroepen |
| **Lange running operations zonder continuations** | 5 sec limiet |
| **External API calls** | Niet ondersteund in JavaScript runtime |
| **Shared state tussen executions** | Elke execution is geïsoleerd |
