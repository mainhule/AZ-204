# 🔌 Azure Cosmos DB - API Models

## 📖 Wat zijn API Models?

Azure Cosmos DB ondersteunt **meerdere API's** waarmee je kunt communiceren met je database. Elk API model emuleert een specifieke database technologie, waardoor je bestaande code en tools kunt hergebruiken.

**Belangrijke eigenschap:** Alle API models retourneren data als **JSON**, ongeacht het gekozen API model.

---

## 🎯 Beschikbare API Models

Azure Cosmos DB biedt **6 verschillende API models**:

```
┌────────────────────────────────────────────────┐
│          Azure Cosmos DB Platform              │
├────────────────────────────────────────────────┤
│  API for NoSQL         ⭐ Native, Recommended │
│  API for MongoDB       🍃 Document-based       │
│  API for PostgreSQL    🐘 Relational-style     │
│  API for Cassandra     📊 Column-family        │
│  API for Table         📋 Key-Value            │
│  API for Gremlin       🕸️ Graph-based          │
└────────────────────────────────────────────────┘
```

**⚠️ Belangrijk:** Het API model is een **account-level** keuze die je maakt bij het aanmaken van het account en **kan niet worden gewijzigd** na creatie.

---

## ⭐ 1. API for NoSQL (Core SQL API)

**💡 Omschrijving:**  
De **native API** van Cosmos DB. Document-georiënteerd met SQL-achtige query syntax.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | JSON documents |
| **Query language** | SQL-like syntax |
| **Native support** | ✅ Volledige Cosmos DB features |
| **Best performance** | ⚡ Optimaal voor Cosmos DB |
| **Use case** | ⭐ **Recommended default** voor nieuwe projecten |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Nieuwe applicaties** zonder legacy dependencies
- **Hierarchical data** (nested JSON structures)
- **Complex queries** met filters, joins, aggregations
- **Schema-less** data met variabele structuur
- **Web & mobile apps** met JSON-first architectuur

### 💻 Voorbeeld

```json
// Document in API for NoSQL
{
  "id": "user-123",
  "name": "John Doe",
  "email": "john@example.com",
  "address": {
    "street": "Main Street 1",
    "city": "Amsterdam",
    "country": "Netherlands"
  },
  "orders": [
    { "orderId": "order-1", "total": 99.99 },
    { "orderId": "order-2", "total": 149.50 }
  ]
}
```

```sql
-- Query in SQL-like syntax
SELECT c.name, c.address.city, VALUE o
FROM c
JOIN o IN c.orders
WHERE c.address.country = 'Netherlands' 
  AND o.total > 100
```

```csharp
// C# SDK voorbeeld
using Microsoft.Azure.Cosmos;

var cosmosClient = new CosmosClient("<endpoint>", "<key>");
var container = cosmosClient.GetContainer("database", "users");

// Point read
ItemResponse<User> response = await container.ReadItemAsync<User>(
    id: "user-123",
    partitionKey: new PartitionKey("user-123")
);

// Query
var query = new QueryDefinition(
    "SELECT * FROM c WHERE c.address.country = @country"
).WithParameter("@country", "Netherlands");

FeedIterator<User> iterator = container.GetItemQueryIterator<User>(query);
```

**🔗 Referentie:** [API for NoSQL Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/nosql/)

## 🍃 2. API for MongoDB

**💡 Omschrijving:**  
Emuleert **MongoDB** protocol en data format (BSON). Wire protocol compatible met MongoDB drivers.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | BSON documents (Binary JSON) |
| **Query language** | MongoDB Query Language (MQL) |
| **Compatibility** | MongoDB drivers v3.6+ |
| **Migration** | ✅ Eenvoudige migratie van bestaande MongoDB apps |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Bestaande MongoDB applicaties** die je wilt migreren naar cloud
- **Teams met MongoDB expertise**
- **Gebruik van MongoDB tools** (Compass, Robo 3T, etc.)
- **MongoDB ODMs** (Mongoose, Motor, etc.)

### 💻 Voorbeeld

```javascript
// MongoDB syntax (Node.js)
const { MongoClient } = require('mongodb');

const uri = "mongodb://<account-name>:<password>@<account-name>.mongo.cosmos.azure.com:10255/?ssl=true";
const client = new MongoClient(uri);

await client.connect();
const database = client.db('myDatabase');
const collection = database.collection('users');

// Insert document
await collection.insertOne({
  _id: "user-123",
  name: "John Doe",
  email: "john@example.com",
  address: {
    city: "Amsterdam",
    country: "Netherlands"
  }
});

// Query documents (MongoDB syntax)
const users = await collection.find({
  "address.country": "Netherlands",
  "age": { $gt: 25 }
}).toArray();

// Aggregation pipeline
const results = await collection.aggregate([
  { $match: { "address.country": "Netherlands" } },
  { $group: { _id: "$address.city", count: { $sum: 1 } } },
  { $sort: { count: -1 } }
]).toArray();
```

**⚠️ Beperkingen:**
- Niet alle MongoDB features worden ondersteund
- Sommige advanced aggregations kunnen verschillen in gedrag

**🔗 Referentie:** [API for MongoDB Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/mongodb/introduction)

## 🐘 3. API for PostgreSQL

**💡 Omschrijving:**  
Distributed PostgreSQL database met horizontale schaalbaarheid. Data kan worden gedistribueerd over nodes of op één node.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | Relational tables (rows & columns) |
| **Query language** | PostgreSQL SQL dialect |
| **Topology** | Single-node of multi-node (distributed) |
| **Compatibility** | PostgreSQL drivers & tools |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Relational data** met foreign keys en constraints
- **SQL-first teams** met PostgreSQL kennis
- **Multi-tenant SaaS** apps met sharding requirements
- **Migratie van PostgreSQL** naar Cosmos DB

### 💻 Voorbeeld

```sql
-- PostgreSQL syntax
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100),
    email VARCHAR(100),
    country VARCHAR(50)
);

INSERT INTO users (name, email, country)
VALUES ('John Doe', 'john@example.com', 'Netherlands');

-- Query met JOIN
SELECT u.name, o.order_id, o.total
FROM users u
INNER JOIN orders o ON u.id = o.user_id
WHERE u.country = 'Netherlands' AND o.total > 100;
```

```csharp
// C# met Npgsql
using Npgsql;

var connString = "Host=<account-name>.postgres.cosmos.azure.com;Port=5432;Database=mydb;User Id=<user>;Password=<password>;Ssl Mode=Require;";

using var conn = new NpgsqlConnection(connString);
await conn.OpenAsync();

using var cmd = new NpgsqlCommand("SELECT * FROM users WHERE country = @country", conn);
cmd.Parameters.AddWithValue("country", "Netherlands");

using var reader = await cmd.ExecuteReaderAsync();
while (await reader.ReadAsync())
{
    Console.WriteLine($"{reader["name"]}: {reader["email"]}");
}
```

**⚠️ Verschillen met standaard PostgreSQL:**
- Distributed mode heeft sharding considerations
- Sommige PostgreSQL extensions niet ondersteund

**🔗 Referentie:** [API for PostgreSQL Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/postgresql/)

## 📊 4. API for Apache Cassandra

**💡 Omschrijving:**  
Emuleert **Apache Cassandra** protocol en data model. Wire protocol compatible met CQL (Cassandra Query Language).

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | Column-family (wide-column) |
| **Query language** | CQL (Cassandra Query Language) |
| **Compatibility** | Cassandra drivers |
| **Architecture** | Distributed, partitioned |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Bestaande Cassandra apps** migreren naar managed service
- **Time-series data** (IoT telemetry, logs)
- **Write-heavy workloads** met horizontal scaling
- **Wide-column data model**

### 💻 Voorbeeld

```cql
-- CQL syntax
CREATE KEYSPACE IF NOT EXISTS myKeyspace 
WITH REPLICATION = {'class': 'SimpleStrategy', 'replication_factor': 1};

USE myKeyspace;

CREATE TABLE users (
    user_id UUID PRIMARY KEY,
    name TEXT,
    email TEXT,
    country TEXT
);

INSERT INTO users (user_id, name, email, country)
VALUES (uuid(), 'John Doe', 'john@example.com', 'Netherlands');

-- Query
SELECT * FROM users WHERE country = 'Netherlands' ALLOW FILTERING;
```

```csharp
// C# met Cassandra driver
using Cassandra;

var cluster = Cluster.Builder()
    .AddContactPoint("<account-name>.cassandra.cosmos.azure.com")
    .WithPort(10350)
    .WithCredentials("<username>", "<password>")
    .WithSSL()
    .Build();

var session = cluster.Connect("myKeyspace");

// Execute query
var statement = new SimpleStatement(
    "SELECT * FROM users WHERE country = ?", 
    "Netherlands"
);
var rowSet = await session.ExecuteAsync(statement);

foreach (var row in rowSet)
{
    Console.WriteLine($"{row["name"]}: {row["email"]}");
}
```

**🔗 Referentie:** [API for Cassandra Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/cassandra/introduction)

## 📋 5. API for Table

**💡 Omschrijving:**  
Emuleert **Azure Table Storage** met verbeterde performance en global distribution. Key-value store.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | Key-value (entities met properties) |
| **Query language** | OData filters |
| **Compatibility** | Azure Table Storage SDK |
| **Use case** | Simple key-value scenarios |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Migratie van Azure Table Storage** voor betere performance
- **Simple key-value storage** zonder complexe relationships
- **OLTP scenarios** (Online Transaction Processing)
- **Schema-less entities**

❌ **Niet geschikt voor:**
- **Complex queries** met JOINs
- **Aggregations** en analytics
- **OLAP workloads**

### 💻 Voorbeeld

```csharp
// C# met Azure.Data.Tables
using Azure.Data.Tables;

var connectionString = "DefaultEndpointsProtocol=https;AccountName=<account-name>;AccountKey=<key>;TableEndpoint=https://<account-name>.table.cosmos.azure.com:443/;";
var tableClient = new TableClient(connectionString, "users");

// Create table
await tableClient.CreateIfNotExistsAsync();

// Insert entity (key-value)
var entity = new TableEntity("Netherlands", "user-123") // PartitionKey, RowKey
{
    { "Name", "John Doe" },
    { "Email", "john@example.com" },
    { "Age", 30 }
};
await tableClient.AddEntityAsync(entity);

// Query entities
var query = tableClient.QueryAsync<TableEntity>(
    filter: $"PartitionKey eq 'Netherlands' and Age gt 25"
);

await foreach (var e in query)
{
    Console.WriteLine($"{e["Name"]}: {e["Email"]}");
}
```

**⚠️ Beperkingen:**
- Geen JOINS of aggregations
- Beperkte query capabilities vergeleken met NoSQL API
- Alleen OLTP (geen OLAP)

**🔗 Referentie:** [API for Table Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/table/introduction)

## 🕸️ 6. API for Apache Gremlin (Graph)

**💡 Omschrijving:**  
Graph database API voor **highly interconnected data**. Ondersteunt Gremlin query language voor graph traversals.

### 📊 Karakteristieken

| Aspect | Details |
|--------|---------|
| **Data model** | Graph (vertices & edges) |
| **Query language** | Gremlin (graph traversal language) |
| **Use case** | Complex relationships & network analysis |
| **Compatibility** | TinkerPop framework |

### 🎯 Wanneer Te Gebruiken

✅ **Ideaal voor:**
- **Social networks** (friend relationships, followers)
- **Recommendation engines** (product recommendations)
- **Fraud detection** (pattern matching in transactions)
- **Knowledge graphs** (semantic relationships)
- **Network topology** (infrastructure dependencies)

❌ **Niet geschikt voor:**
- Simpele hierarchical data (gebruik NoSQL API)
- Data zonder complexe relationships

### 💻 Voorbeeld

```javascript
// Gremlin query syntax (Node.js met gremlin driver)
const gremlin = require('gremlin');

const authenticator = new gremlin.driver.auth.PlainTextSaslAuthenticator(
    `/dbs/<database>/colls/<graph>`,
    '<primary-key>'
);

const client = new gremlin.driver.Client(
    'wss://<account-name>.gremlin.cosmos.azure.com:443/',
    { authenticator }
);

// Add vertices (nodes)
await client.submit("g.addV('person').property('id', 'john').property('name', 'John Doe')");
await client.submit("g.addV('person').property('id', 'jane').property('name', 'Jane Doe')");

// Add edge (relationship)
await client.submit("g.V('john').addE('knows').to(g.V('jane'))");

// Traverse graph: Find all people John knows
const results = await client.submit("g.V('john').out('knows').values('name')");
// Results: ["Jane Doe"]

// Complex traversal: Find friends of friends
const fof = await client.submit(
    "g.V('john').out('knows').out('knows').dedup().values('name')"
);
```

**Graph Concepten:**
```
Vertices (Nodes):        Edges (Relationships):
┌──────────┐            ┌─────────────────┐
│  Person  │            │  knows          │
│  id: john│───────────>│  since: 2020    │
└──────────┘            └─────────────────┘
                                 │
                                 v
                        ┌──────────┐
                        │  Person  │
                        │  id: jane│
                        └──────────┘
```

**🔗 Referentie:** [API for Gremlin Documentation](https://docs.microsoft.com/en-us/azure/cosmos-db/graph/introduction)

## 📊 API Model Vergelijking

| API | Data Model | Query Language | Best For | Migration From |
|-----|------------|----------------|----------|----------------|
| **NoSQL** ⭐ | Document (JSON) | SQL-like | New apps, flexible schemas | N/A (native) |
| **MongoDB** 🍃 | Document (BSON) | MQL | MongoDB apps | MongoDB |
| **PostgreSQL** 🐘 | Relational | PostgreSQL SQL | SQL apps, multi-tenant | PostgreSQL |
| **Cassandra** 📊 | Column-family | CQL | Time-series, write-heavy | Cassandra |
| **Table** 📋 | Key-value | OData filters | Simple OLTP | Azure Table Storage |
| **Gremlin** 🕸️ | Graph | Gremlin | Complex relationships | TinkerPop graphs |

## 🎯 Decision Tree: Welk API Model?

```
START: Kies een API Model
  │
  ├─❓ Heb je bestaande code voor een specifieke database?
  │   ├─ MongoDB → API for MongoDB 🍃
  │   ├─ PostgreSQL → API for PostgreSQL 🐘
  │   ├─ Cassandra → API for Cassandra 📊
  │   ├─ Azure Table Storage → API for Table 📋
  │   └─ Geen legacy code ↓
  │
  ├─❓ Wat voor data model heb je?
  │   ├─ Complexe relaties (social graph) → API for Gremlin 🕸️
  │   ├─ Relational met JOINs → API for PostgreSQL 🐘
  │   ├─ Time-series, logs → API for Cassandra 📊
  │   ├─ Simple key-value → API for Table 📋
  │   └─ Flexible JSON documents ↓
  │
  └─ ⭐ API for NoSQL (Recommended voor nieuwe apps)
```

## ⚙️ Account Creatie Per API

```bash
# API for NoSQL (default)
az cosmosdb create \
  --name mycosmosaccount \
  --resource-group myResourceGroup \
  --kind GlobalDocumentDB \
  --locations regionName=westeurope

# API for MongoDB
az cosmosdb create \
  --name mymongodbaccount \
  --resource-group myResourceGroup \
  --kind MongoDB \
  --server-version 4.2 \
  --locations regionName=westeurope

# API for Cassandra
az cosmosdb create \
  --name mycassandraaccount \
  --resource-group myResourceGroup \
  --capabilities EnableCassandra \
  --locations regionName=westeurope

# API for Table
az cosmosdb create \
  --name mytableaccount \
  --resource-group myResourceGroup \
  --capabilities EnableTable \
  --locations regionName=westeurope

# API for Gremlin
az cosmosdb create \
  --name mygremlinaccount \
  --resource-group myResourceGroup \
  --capabilities EnableGremlin \
  --locations regionName=westeurope

# API for PostgreSQL
az cosmosdb postgres cluster create \
  --cluster-name mypostgrescluster \
  --resource-group myResourceGroup \
  --location westeurope
```

**⚠️ Belangrijk:** API model kan **NIET worden gewijzigd** na account creatie!

## 🏆 Best Practices

### ✅ Do's

| Praktijk | Reden |
|----------|-------|
| **Kies NoSQL API voor nieuwe apps** | Native API met alle Cosmos DB features |
| **Gebruik legacy API alleen voor migratie** | Vermijd lock-in met emulated APIs |
| **Test compatibility vooraf** | Niet alle features van legacy DB's worden ondersteund |
| **Evalueer query patterns** | Sommige APIs zijn beter voor specifieke query types |
| **Check driver compatibility** | Gebruik supported driver versies |

### ❌ Don'ts

| Anti-pattern | Waarom niet? |
|--------------|---------------|
| **API kiezen op basis van populariteit** | Kies op basis van je use case |
| **Gremlin API voor simple hierarchies** | NoSQL API is efficiënter voor eenvoudige nested data |
| **Table API voor complexe queries** | Zeer beperkte query capabilities |
| **Veronderstellen 100% compatibility** | Test edge cases bij migratie |
| **Mengen van APIs in één account** | Niet mogelijk - één API per account |

---

## 📌 Belangrijke Notities

### 🔒 Account-level Keuze
- API model is een **irreversible** keuze bij account creatie
- Migratie naar ander API vereist nieuw account + data copy

### 📦 JSON Output
- Alle APIs retourneren data als **JSON**, ongeacht intern format
- Dit maakt cross-API integrations eenvoudiger

### ⚡ Performance Verschillen
- **NoSQL API** heeft vaak de **beste performance** (native)
- Legacy APIs hebben overhead door emulation layer

### 💰 Pricing
- Alle APIs gebruiken **dezelfde RU-based pricing**
- Geen verschil in kosten per API model
