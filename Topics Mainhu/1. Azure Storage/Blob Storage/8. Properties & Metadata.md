# 📋 Properties & Metadata

## 🤔 Overview

Elke blob in Azure Storage heeft:
- **System Properties** - Managed by Azure (read-only of read-write)
- **User-Defined Metadata** - Custom key-value pairs

---

## 1️⃣ System Properties

### Wat zijn System Properties?

**Azure-managed** eigenschappen die informatie over de blob bevatten.

### Standard Properties

| Property | Type | Description |
|----------|------|-------------|
| **ETag** | Read-only | Unique identifier, changes bij update |
| **Last-Modified** | Read-only | Last modification timestamp |
| **Content-Length** | Read-only | Blob size in bytes |
| **Content-Type** | Read-write | MIME type (bijv. text/plain) |
| **Content-Encoding** | Read-write | Encoding (bijv. gzip) |
| **Content-Language** | Read-write | Language (bijv. nl-NL) |
| **Content-MD5** | Read-write | MD5 hash voor validation |
| **Cache-Control** | Read-write | Caching directives |

### C# Read Properties

```csharp
BlobProperties properties = await blobClient.GetPropertiesAsync();

// System properties (read-only)
Console.WriteLine($"ETag: {properties.ETag}");
Console.WriteLine($"Last Modified: {properties.LastModified}");
Console.WriteLine($"Content Length: {properties.ContentLength} bytes");
Console.WriteLine($"Blob Type: {properties.BlobType}");

// HTTP headers (read-write)
Console.WriteLine($"Content Type: {properties.ContentType}");
Console.WriteLine($"Content Encoding: {properties.ContentEncoding}");
Console.WriteLine($"Cache Control: {properties.CacheControl}");

// Access tier
Console.WriteLine($"Access Tier: {properties.AccessTier}");
```

### C# Set HTTP Headers

```csharp
var headers = new BlobHttpHeaders
{
    ContentType = "application/pdf",
    ContentLanguage = "nl-NL",
    ContentEncoding = "gzip",
    CacheControl = "public, max-age=86400",
    ContentDisposition = "attachment; filename=document.pdf"
};

await blobClient.SetHttpHeadersAsync(headers);
```

### CLI Get Properties

```bash
az storage blob show \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --auth-mode login
```

### HTTP Headers (REST API)

```http
GET https://account.blob.core.windows.net/container/blob HTTP/1.1

Response Headers:
ETag: "0x8D9..."
Last-Modified: Mon, 15 Jan 2024 10:30:00 GMT
Content-Length: 1024
Content-Type: text/plain
Content-Encoding: gzip
Cache-Control: public, max-age=3600
```

## 2️⃣ User-Defined Metadata

### Wat is Metadata?

**Custom key-value pairs** die je zelf kunt instellen voor je eigen doeleinden.

### Rules & Constraints

```
✅ HTTP header format
✅ Valid C# identifiers
✅ ASCII characters only
✅ Case-insensitive (treated as lowercase)
✅ Max 8 KB total size
✅ Non-ASCII = Base64/URL encode

Format:
├── Name: Valid HTTP header name
└── Value: String value
```

### Naming Examples

```
✅ department
✅ project-name
✅ category_id
✅ owner-email

❌ 123metadata (starts with number)
❌ meta data (space)
❌ meta/data (invalid character)
```

### C# Set Metadata

```csharp
var metadata = new Dictionary<string, string>
{
    { "department", "IT" },
    { "project", "AZ-204" },
    { "owner", "john@contoso.com" },
    { "classification", "confidential" }
};

await blobClient.SetMetadataAsync(metadata);
```

### C# Get Metadata

```csharp
BlobProperties properties = await blobClient.GetPropertiesAsync();

foreach (var tag in properties.Metadata)
{
    Console.WriteLine($"{tag.Key}: {tag.Value}");
}

// Output:
// department: IT
// project: AZ-204
// owner: john@contoso.com
// classification: confidential
```

### CLI Set Metadata

```bash
az storage blob metadata update \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --metadata department=IT project=AZ-204 \
  --auth-mode login
```

### CLI Get Metadata

```bash
az storage blob metadata show \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --auth-mode login
```

### HTTP Metadata Headers (REST API)

**Set Metadata (PUT):**
```http
PUT https://account.blob.core.windows.net/container/blob?comp=metadata HTTP/1.1
x-ms-version: 2021-06-08
x-ms-meta-department: IT
x-ms-meta-project: AZ-204
x-ms-meta-owner: john@contoso.com
Authorization: ...
```

**Get Metadata (GET/HEAD):**
```http
GET https://account.blob.core.windows.net/container/blob?comp=metadata HTTP/1.1
x-ms-version: 2021-06-08
Authorization: ...

Response Headers:
x-ms-meta-department: IT
x-ms-meta-project: AZ-204
x-ms-meta-owner: john@contoso.com
```

### ⚠️ Important Behaviors

#### Azure CLI vs REST API

**Azure CLI:**
```bash
# Twee headers met zelfde naam:
x-ms-meta-category: documents
x-ms-meta-category: reports

# Result: ERROR (CLI doesn't support duplicate)
```

**REST API:**
```http
x-ms-meta-category: documents
x-ms-meta-category: reports

# Result: OK
# Values concatenated: "documents,reports"
# HTTP 200 OK
```

#### Partial Updates Not Supported

```
❌ Cannot update single metadata key
✅ Must provide complete metadata dictionary

Example:
Existing: {department: IT, project: AZ-204}
Update: {owner: john}
Result: {owner: john}  # department & project LOST!

Solution: Get, Modify, Set
```

## 3️⃣ Access Conditions

### Wat zijn Access Conditions?

**Conditional operations** gebaseerd op blob state - gebruikt voor **optimistic concurrency**.

### Condition Types

| Condition | Description | Use Case |
|-----------|-------------|----------|
| **IfMatch** | ETag moet matchen | Update only if not changed |
| **IfNoneMatch** | ETag moet NIET matchen | Create only if not exists |
| **IfModifiedSince** | Modified after timestamp | Get updates since last check |
| **IfUnmodifiedSince** | Not modified after timestamp | Update only if stable |
| **LeaseId** | Active lease ID | Coordinate concurrent access |
| **TagConditions** | SQL query on tags | Filter by blob index tags |

### C# Examples

#### ETag Conditions (Optimistic Concurrency)

```csharp
// Get current ETag
BlobProperties properties = await blobClient.GetPropertiesAsync();
ETag etag = properties.ETag;

// Update only if ETag matches (not modified)
var conditions = new BlobRequestConditions
{
    IfMatch = etag
};

try
{
    await blobClient.UploadAsync(stream, conditions: conditions);
    Console.WriteLine("Update successful");
}
catch (RequestFailedException ex) when (ex.Status == 412)
{
    Console.WriteLine("Blob was modified - ETag mismatch!");
}

// Upload only if blob doesn't exist
conditions = new BlobRequestConditions
{
    IfNoneMatch = ETag.All // Matches any ETag = fails if exists
};

await blobClient.UploadAsync(stream, conditions: conditions);
```

#### Time-based Conditions

```csharp
var conditions = new BlobRequestConditions
{
    // Only if modified in last hour
    IfModifiedSince = DateTimeOffset.UtcNow.AddHours(-1),
    
    // Only if NOT modified in last hour
    IfUnmodifiedSince = DateTimeOffset.UtcNow.AddHours(-1)
};

await blobClient.UploadAsync(stream, conditions: conditions);
```

#### Lease Conditions

```csharp
// Acquire lease
var leaseClient = blobClient.GetBlobLeaseClient();
BlobLease lease = await leaseClient.AcquireAsync(TimeSpan.FromSeconds(30));

// Operations require lease ID
var conditions = new BlobRequestConditions
{
    LeaseId = lease.LeaseId
};

await blobClient.UploadAsync(stream, conditions: conditions);

// Without lease ID: 412 Precondition Failed
```

#### Tag Conditions

```csharp
// Set blob tags first
await blobClient.SetTagsAsync(new Dictionary<string, string>
{
    { "Status", "Processed" },
    { "Environment", "Production" }
});

// Conditional operation based on tags
var conditions = new BlobRequestConditions
{
    TagConditions = "Status = 'Processed' AND Environment = 'Production'"
};

await blobClient.DeleteAsync(conditions: conditions);
```

### CLI Access Conditions

```bash
# If-Match (ETag)
az storage blob upload \
  --name myblob.txt \
  --file ./file.txt \
  --if-match "0x8D9..."

# If-None-Match (create only if not exists)
az storage blob upload \
  --name myblob.txt \
  --file ./file.txt \
  --if-none-match "*"

# If-Modified-Since
az storage blob download \
  --name myblob.txt \
  --file ./file.txt \
  --if-modified-since "2024-01-01T00:00:00Z"

# Tag conditions
az storage blob delete \
  --name myblob.txt \
  --tags-condition "Status = 'Processed'"
```

### HTTP Conditional Headers

```http
PUT https://account.blob.core.windows.net/container/blob HTTP/1.1
If-Match: "0x8D9..."
If-None-Match: "*"
If-Modified-Since: Mon, 15 Jan 2024 10:00:00 GMT
If-Unmodified-Since: Mon, 15 Jan 2024 12:00:00 GMT
x-ms-lease-id: <lease-id>
x-ms-if-tags: Status = 'Processed'
```

### Error Responses

```
412 Precondition Failed:
├── IfMatch failed (ETag mismatch)
├── IfNoneMatch failed (blob exists)
├── IfModifiedSince failed (not modified)
├── IfUnmodifiedSince failed (was modified)
├── LeaseId mismatch
└── TagConditions not met

304 Not Modified:
└── IfModifiedSince condition not met (GET/HEAD)
```

## 💡 Common Use Cases

### 1. Document Management System

```csharp
// Upload document with metadata
var metadata = new Dictionary<string, string>
{
    { "documentType", "invoice" },
    { "customerId", "12345" },
    { "fiscalYear", "2024" },
    { "department", "finance" }
};

var headers = new BlobHttpHeaders
{
    ContentType = "application/pdf",
    ContentDisposition = "attachment; filename=invoice.pdf"
};

await blobClient.UploadAsync(
    pdfStream,
    new BlobUploadOptions
    {
        Metadata = metadata,
        HttpHeaders = headers
    }
);

// Search documents by metadata
await foreach (BlobItem item in containerClient.GetBlobsAsync(
    BlobTraits.Metadata))
{
    if (item.Metadata.TryGetValue("fiscalYear", out string year) && year == "2024")
    {
        Console.WriteLine($"Found: {item.Name}");
    }
}
```

### 2. Optimistic Concurrency Control

```csharp
// User A reads document
var propertiesA = await blobClient.GetPropertiesAsync();
string contentA = await blobClient.DownloadContentAsync();

// User B reads document
var propertiesB = await blobClient.GetPropertiesAsync();
string contentB = await blobClient.DownloadContentAsync();

// User B saves first (succeeds)
await blobClient.UploadAsync(
    modifiedContentB,
    conditions: new BlobRequestConditions { IfMatch = propertiesB.Value.ETag }
);

// User A tries to save (fails - ETag changed)
try
{
    await blobClient.UploadAsync(
        modifiedContentA,
        conditions: new BlobRequestConditions { IfMatch = propertiesA.Value.ETag }
    );
}
catch (RequestFailedException ex) when (ex.Status == 412)
{
    Console.WriteLine("Document was modified by another user!");
    // Handle conflict: reload, merge, or ask user
}
```

### 3. Cache Control

```csharp
// Static assets with long cache
var headers = new BlobHttpHeaders
{
    ContentType = "image/jpeg",
    CacheControl = "public, max-age=31536000, immutable" // 1 year
};

await imageBlobClient.SetHttpHeadersAsync(headers);

// Dynamic content with short cache
headers = new BlobHttpHeaders
{
    ContentType = "application/json",
    CacheControl = "no-cache, must-revalidate"
};

await apiResponseBlobClient.SetHttpHeadersAsync(headers);
```

### 4. Content Classification

```csharp
// Classify uploaded files
var metadata = new Dictionary<string, string>
{
    { "classification", "confidential" },
    { "dataRetention", "7years" },
    { "encryption", "required" }
};

```

## ✅ Best Practices

### 1. Metadata Naming

```
✅ Use descriptive names:
   department, projectName, ownerId

✅ Use lowercase (case-insensitive anyway):
   category, not Category

✅ Use delimiters for namespaces:
   app_version, user_role

❌ Avoid special characters:
   Not: user@email (use: userEmail)
```

### 2. Content-Type

```
✅ Always set correct Content-Type:
   text/plain, application/json, image/jpeg

✅ Critical for browser rendering:
   Browser uses Content-Type to display content

❌ Default is application/octet-stream:
   Browser downloads instead of displays
```

### 3. Cache-Control

```
Static assets (images, CSS, JS):
└── Cache-Control: public, max-age=31536000, immutable

Dynamic content (API responses):
└── Cache-Control: no-cache, must-revalidate

Semi-static (updated daily):
└── Cache-Control: public, max-age=86400
```

### 4. ETag for Concurrency

```
✅ Use IfMatch for updates:
   Prevents lost updates

✅ Use IfNoneMatch for creates:
   Prevents duplicates

✅ Handle 412 gracefully:
   Reload, retry, or ask user
```

### 5. Metadata Size

```
⚠️ Max 8 KB total metadata
✅ Keep values concise
✅ Don't store large data
✅ Use blob content for large data

Example:
❌ metadata["description"] = "Very long description..."
✅ metadata["descriptionBlobName"] = "description.txt"
```

## 🎓 Samenvatting

### Key Takeaways

1. **System Properties** - Azure-managed (ETag, Last-Modified, Content-Type)
2. **User Metadata** - Custom key-value pairs (max 8 KB)
3. **Access Conditions** - Optimistic concurrency met ETag
4. **HTTP Headers** - Content-Type, Cache-Control, etc.
5. **Partial updates** - Not supported (always full replace)
6. **Case-insensitive** - Metadata names treated as lowercase

### Quick Reference

```csharp
// Get properties
var props = await blobClient.GetPropertiesAsync();
Console.WriteLine($"ETag: {props.Value.ETag}");

// Set metadata
await blobClient.SetMetadataAsync(new Dictionary<string, string>
{
    { "key", "value" }
});

// Set HTTP headers
await blobClient.SetHttpHeadersAsync(new BlobHttpHeaders
{
    ContentType = "text/plain",
    CacheControl = "public, max-age=3600"
});

// Conditional upload
await blobClient.UploadAsync(stream, conditions: new BlobRequestConditions
{
    IfMatch = etag
});
```

### Decision Guide

```
Use System Properties for:
├── Size information (Content-Length)
├── Change tracking (ETag, Last-Modified)
└── HTTP behavior (Content-Type, Cache-Control)

Use Metadata for:
├── Business data (department, project)
├── Classification (confidential, public)
├── Ownership (owner, creator)
└── Custom attributes (any key-value)

Use Access Conditions for:
├── Optimistic concurrency (IfMatch)
├── Conditional creates (IfNoneMatch)
├── Time-based logic (IfModifiedSince)
└── Coordinated access (LeaseId)
```
