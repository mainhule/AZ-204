# 💻 Working with Blobs

## 🛠️ Drie Manieren om met Blobs te Werken

1. **Azure CLI** - Command-line interface
2. **C# SDK** - Programmatic access (.NET)
3. **HTTP REST API** - Direct HTTP calls

---

## 1️⃣ Azure CLI

### Authentication

```bash
# Method 1: Account Key
az storage blob <command> \
  --account-name mystorageaccount \
  --account-key "your-key"

# Method 2: Entra ID (az login)
az storage blob <command> \
  --account-name mystorageaccount \
  --auth-mode login

# Method 3: Connection String
az storage blob <command> \
  --connection-string "DefaultEndpointsProtocol=https;..."

# Method 4: SAS Token
az storage blob <command> \
  --account-name mystorageaccount \
  --sas-token "sv=2021-06-08&ss=b..."
```

### Upload Blob

```bash
# Upload file
az storage blob upload \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --file ./local-file.txt \
  --auth-mode login

# Upload with tier
az storage blob upload \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --file ./local-file.txt \
  --tier Cool

# Upload text data
az storage blob upload \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --data "Hello, World!" \
  --auth-mode login
```

### Download Blob

```bash
# Download to file
az storage blob download \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --file ./downloaded-file.txt \
  --auth-mode login

# Download to stdout
az storage blob download \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --no-progress \
  --auth-mode login
```

### List Blobs

```bash
# List all blobs in container
az storage blob list \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --auth-mode login \
  --output table

# List with prefix
az storage blob list \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --prefix "logs/" \
  --auth-mode login

# List including metadata
az storage blob list \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --include metadata \
  --auth-mode login
```

### Delete Blob

```bash
# Delete blob
az storage blob delete \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --auth-mode login

# Delete with snapshots
az storage blob delete \
  --account-name mystorageaccount \
  --container-name mycontainer \
  --name myblob.txt \
  --delete-snapshots include \
  --auth-mode login
```

### Copy Blob

```bash
# Copy within same account
az storage blob copy start \
  --account-name mystorageaccount \
  --destination-container targetcontainer \
  --destination-blob targetblob.txt \
  --source-container sourcecontainer \
  --source-blob sourceblob.txt \
  --auth-mode login

# Copy from URL
az storage blob copy start \
  --account-name mystorageaccount \
  --destination-container mycontainer \
  --destination-blob myblob.txt \
  --source-uri "https://sourceaccount.blob.core.windows.net/container/blob"
```

### Container Operations

```bash
# Create container
az storage container create \
  --account-name mystorageaccount \
  --name mycontainer \
  --auth-mode login

# List containers
az storage container list \
  --account-name mystorageaccount \
  --auth-mode login \
  --output table

# Delete container
az storage container delete \
  --account-name mystorageaccount \
  --name mycontainer \
  --auth-mode login
```

## 2️⃣ C# SDK (.NET)

### Setup

```bash
dotnet add package Azure.Storage.Blobs
```

```csharp
using Azure.Storage.Blobs;
using Azure.Storage.Blobs.Models;
using Azure.Identity;
```

### Authentication

```csharp
// Method 1: Connection String
string connectionString = "DefaultEndpointsProtocol=https;AccountName=...";
var blobServiceClient = new BlobServiceClient(connectionString);

// Method 2: Account Key
string accountName = "mystorageaccount";
string accountKey = "your-key";
var credential = new StorageSharedKeyCredential(accountName, accountKey);
var blobServiceClient = new BlobServiceClient(
    new Uri($"https://{accountName}.blob.core.windows.net"),
    credential
);

// Method 3: Entra ID (DefaultAzureCredential)
var credential = new DefaultAzureCredential();
var blobServiceClient = new BlobServiceClient(
    new Uri("https://mystorageaccount.blob.core.windows.net"),
    credential
);

// Method 4: SAS Token
string sasToken = "sv=2021-06-08&ss=b&srt=sco&sp=rwdlac&se=...";
var blobServiceClient = new BlobServiceClient(
    new Uri($"https://mystorageaccount.blob.core.windows.net?{sasToken}")
);
```

### Upload Blob

```csharp
// Get container client
BlobContainerClient containerClient = blobServiceClient.GetBlobContainerClient("mycontainer");
await containerClient.CreateIfNotExistsAsync();

// Get blob client
BlobClient blobClient = containerClient.GetBlobClient("myblob.txt");

// Upload from file
await blobClient.UploadAsync("./local-file.txt", overwrite: true);

// Upload from stream
using (FileStream fileStream = File.OpenRead("./local-file.txt"))
{
    await blobClient.UploadAsync(fileStream, overwrite: true);
}

// Upload from byte array
byte[] data = Encoding.UTF8.GetBytes("Hello, World!");
using (MemoryStream stream = new MemoryStream(data))
{
    await blobClient.UploadAsync(stream, overwrite: true);
}

// Upload with options
var uploadOptions = new BlobUploadOptions
{
    AccessTier = AccessTier.Cool,
    Metadata = new Dictionary<string, string>
    {
        { "department", "IT" },
        { "project", "AZ-204" }
    },
    HttpHeaders = new BlobHttpHeaders
    {
        ContentType = "text/plain",
        CacheControl = "public, max-age=3600"
    }
};

await blobClient.UploadAsync("./local-file.txt", uploadOptions);
```

### Download Blob

```csharp
// Download to file
await blobClient.DownloadToAsync("./downloaded-file.txt");

// Download to stream
using (FileStream fileStream = File.OpenWrite("./downloaded-file.txt"))
{
    await blobClient.DownloadToAsync(fileStream);
}

// Download with BlobDownloadInfo
BlobDownloadInfo download = await blobClient.DownloadAsync();
using (StreamReader reader = new StreamReader(download.Content))
{
    string content = await reader.ReadToEndAsync();
    Console.WriteLine(content);
}

// Download range
HttpRange range = new HttpRange(0, 1024); // First 1KB
BlobDownloadInfo download = await blobClient.DownloadAsync(range);
```

### List Blobs

```csharp
// List all blobs
await foreach (BlobItem blobItem in containerClient.GetBlobsAsync())
{
    Console.WriteLine($"Blob: {blobItem.Name}");
    Console.WriteLine($"Size: {blobItem.Properties.ContentLength} bytes");
    Console.WriteLine($"Tier: {blobItem.Properties.AccessTier}");
}

// List with prefix
await foreach (BlobItem blobItem in containerClient.GetBlobsAsync(prefix: "logs/"))
{
    Console.WriteLine($"Log file: {blobItem.Name}");
}

// List with metadata
await foreach (BlobItem blobItem in containerClient.GetBlobsAsync(
    BlobTraits.Metadata))
{
    Console.WriteLine($"Blob: {blobItem.Name}");
    foreach (var tag in blobItem.Metadata)
    {
        Console.WriteLine($"  {tag.Key}: {tag.Value}");
    }
}

// List hierarchically (virtual folders)
await foreach (BlobHierarchyItem item in containerClient.GetBlobsByHierarchyAsync(
    delimiter: "/"))
{
    if (item.IsPrefix)
    {
        Console.WriteLine($"Folder: {item.Prefix}");
    }
    else
    {
        Console.WriteLine($"Blob: {item.Blob.Name}");
    }
}
```

### Delete Blob

```csharp
// Delete blob
await blobClient.DeleteAsync();

// Delete if exists
await blobClient.DeleteIfExistsAsync();

// Delete with snapshots
await blobClient.DeleteAsync(DeleteSnapshotsOption.IncludeSnapshots);

// Soft delete (if enabled)
await blobClient.DeleteAsync(); // Goes to soft delete

// Undelete (restore from soft delete)
await blobClient.UndeleteAsync();
```

### Copy Blob

```csharp
// Copy within same account
BlobClient sourceBlob = containerClient.GetBlobClient("source.txt");
BlobClient targetBlob = containerClient.GetBlobClient("target.txt");

await targetBlob.StartCopyFromUriAsync(sourceBlob.Uri);

// Copy across accounts (requires SAS or public access)
Uri sourceUri = new Uri("https://sourceaccount.blob.core.windows.net/container/blob?sas");
await targetBlob.StartCopyFromUriAsync(sourceUri);

// Wait for copy completion
var operation = await targetBlob.StartCopyFromUriAsync(sourceBlob.Uri);
await operation.WaitForCompletionAsync();
```

### Properties & Metadata

```csharp
// Get properties
BlobProperties properties = await blobClient.GetPropertiesAsync();
Console.WriteLine($"Content Type: {properties.ContentType}");
Console.WriteLine($"Size: {properties.ContentLength} bytes");
Console.WriteLine($"ETag: {properties.ETag}");
Console.WriteLine($"Last Modified: {properties.LastModified}");

// Set metadata
var metadata = new Dictionary<string, string>
{
    { "department", "IT" },
    { "category", "documents" }
};
await blobClient.SetMetadataAsync(metadata);

// Get metadata
properties = await blobClient.GetPropertiesAsync();
foreach (var tag in properties.Metadata)
{
    Console.WriteLine($"{tag.Key}: {tag.Value}");
}

// Set HTTP headers
var headers = new BlobHttpHeaders
{
    ContentType = "application/pdf",
    ContentLanguage = "nl-NL",
    CacheControl = "public, max-age=86400"
};
await blobClient.SetHttpHeadersAsync(headers);
```

### Conditional Operations (ETag)

```csharp
// Get current properties
BlobProperties properties = await blobClient.GetPropertiesAsync();
ETag etag = properties.ETag;

// Update only if not modified (optimistic concurrency)
var conditions = new BlobRequestConditions
{
    IfMatch = etag
};

try
{
    await blobClient.UploadAsync(stream, conditions: conditions);
    Console.WriteLine("Update successful");
}
catch (RequestFailedException ex) when (ex.Status == 412)
{
    Console.WriteLine("Blob was modified by someone else!");
}
```

### Batch Operations

```csharp
// Delete multiple blobs
var blobs = new List<string> { "blob1.txt", "blob2.txt", "blob3.txt" };

foreach (var blobName in blobs)
{
    var blob = containerClient.GetBlobClient(blobName);
    await blob.DeleteIfExistsAsync();
}

// Parallel upload
var uploadTasks = blobs.Select(async blobName =>
{
    var blob = containerClient.GetBlobClient(blobName);
    await blob.UploadAsync($"./{blobName}");
});

await Task.WhenAll(uploadTasks);
```

## 3️⃣ HTTP REST API

### Authentication Headers

```http
# Shared Key
Authorization: SharedKey mystorageaccount:<signature>

# Bearer Token (Entra ID)
Authorization: Bearer <access-token>

# SAS Token (in query string)
GET https://account.blob.core.windows.net/container/blob?<sas-token>
```

### Common Headers

```http
x-ms-version: 2021-06-08
x-ms-date: Mon, 15 Jan 2024 10:30:00 GMT
Content-Type: application/octet-stream
```

```http

Host: mystorageaccount.blob.core.windows.net

x-ms-date: Mon, 15 Jan 2024 10:30:00 GMT
x-ms-blob-type: BlockBlob
Content-Type: text/plain
Content-Length: 13
Authorization: SharedKey mystorageaccount:<signature>

Hello, World!
```

## 🔄 AzCopy Tool

### Installatie

```bash
# Download from: https://aka.ms/downloadazcopy

# Verify installation
azcopy --version
```

### Authentication

```bash
# Login with Entra ID
azcopy login

# Or use SAS token in URL
```

### Upload

```bash
# Upload file
azcopy copy \
  "./local-file.txt" \
  "https://mystorageaccount.blob.core.windows.net/mycontainer/myblob.txt?<sas>"

# Upload folder (recursive)
azcopy copy \
  "./local-folder" \
  "https://mystorageaccount.blob.core.windows.net/mycontainer?<sas>" \
  --recursive=true

# Upload with pattern
azcopy copy \
  "./logs/*.log" \
  "https://mystorageaccount.blob.core.windows.net/logs?<sas>" \
  --recursive=true
```

### Download

```bash
# Download file
azcopy copy \
  "https://mystorageaccount.blob.core.windows.net/mycontainer/myblob.txt?<sas>" \
  "./local-file.txt"

# Download folder
azcopy copy \
  "https://mystorageaccount.blob.core.windows.net/mycontainer?<sas>" \
  "./local-folder" \
  --recursive=true
```

### Sync

```bash
# Sync local to blob (incremental)
azcopy sync \
  "./local-folder" \
  "https://mystorageaccount.blob.core.windows.net/mycontainer?<sas>" \
  --recursive=true \
  --delete-destination=true

# Sync blob to local
azcopy sync \
  "https://mystorageaccount.blob.core.windows.net/mycontainer?<sas>" \
  "./local-folder" \
  --recursive=true
```

### Copy Between Accounts

```bash
# Copy from one account to another
azcopy copy \
  "https://sourceaccount.blob.core.windows.net/container?<source-sas>" \
  "https://targetaccount.blob.core.windows.net/container?<target-sas>" \
  --recursive=true
```

### Performance Options

```bash
azcopy copy \
  "./local-folder" \
  "https://mystorageaccount.blob.core.windows.net/mycontainer?<sas>" \
  --recursive=true \
  --block-size-mb=100 \
  --cap-mbps=500 \
  --log-level=INFO
```

## ✅ Best Practices

### 1. Error Handling

```csharp
try
{
    await blobClient.UploadAsync(stream);
}
catch (RequestFailedException ex) when (ex.Status == 404)
{
    Console.WriteLine("Container niet gevonden");
}
catch (RequestFailedException ex) when (ex.Status == 409)
{
    Console.WriteLine("Blob bestaat al");
}
catch (RequestFailedException ex) when (ex.Status == 412)
{
    Console.WriteLine("Precondition failed (ETag mismatch)");
}
catch (RequestFailedException ex)
{
    Console.WriteLine($"Storage error: {ex.Status} - {ex.Message}");
}
```

### 2. Retry Strategy

```csharp
var options = new BlobClientOptions();
options.Retry.MaxRetries = 5;
options.Retry.Delay = TimeSpan.FromSeconds(2);
options.Retry.MaxDelay = TimeSpan.FromSeconds(10);
options.Retry.Mode = RetryMode.Exponential;

var blobClient = new BlobClient(uri, credential, options);
```

### 3. Progress Tracking

```csharp
var progressHandler = new Progress<long>(bytesTransferred =>
{
    Console.WriteLine($"Uploaded: {bytesTransferred} bytes");
});

await blobClient.UploadAsync(
    stream,
    progressHandler: progressHandler
);
```

### 4. Batch Operations

```bash
# Use AzCopy for large batch operations
# Faster than individual CLI commands

azcopy copy "./data/*" "https://account.blob.core.windows.net/container?sas" \
  --recursive=true \
  --include-pattern="*.log;*.txt"
```

### 5. Large File Uploads

```csharp
// Use BlockBlobClient for large files (>256 MB)
var blockBlobClient = containerClient.GetBlockBlobClient("largefile.zip");

await blockBlobClient.UploadAsync(
    fileStream,
    new BlobUploadOptions
    {
        TransferOptions = new StorageTransferOptions
        {
            MaximumTransferLength = 4 * 1024 * 1024, // 4 MB blocks
            MaximumConcurrency = 4
        }
    }
);
```

## 🎓 Samenvatting

### Key Takeaways

1. **Drie methoden:** Azure CLI, C# SDK, HTTP REST API
2. **Authentication:** Shared Key, Entra ID, SAS, Connection String
3. **CRUD operations:** Upload, Download, List, Delete
4. **Metadata & Properties:** Set and retrieve custom data
5. **Conditional operations:** Use ETag for optimistic concurrency
6. **AzCopy:** Best for bulk operations
7. **Error handling:** Catch RequestFailedException

### Method Vergelijking

| Method | Best Voor | Pros | Cons |
|--------|-----------|------|------|
| **Azure CLI** | Quick tasks, scripts | Simple, fast | Limited automation |
| **C# SDK** | Applications | Full features, typed | Requires code |
| **HTTP API** | Any language | Universal | Manual auth |
| **AzCopy** | Bulk operations | Fast, efficient | CLI only |

### Quick Reference

```bash
# CLI: Upload
az storage blob upload --name blob.txt --file ./file.txt

# C#: Upload
await blobClient.UploadAsync("./file.txt");

# HTTP: Upload
PUT https://account.blob.core.windows.net/container/blob.txt

# AzCopy: Upload folder
azcopy copy "./folder" "https://account.blob.core.windows.net/container?sas" --recursive
```
