# Wanneer welke service gebruiken?

| Service | Gebruik wanneer... |
|---------|-------------------|
| **ACR** | Je container images wilt opslaan en beheren |
| **ACI** | Simpele containers zonder scaling nodig |
| **Container Apps** | Productie apps met auto-scaling en microservices |

**Container Apps vs ACI:**
- Container Apps = ACI + auto-scaling + load balancing + ingress
- ACI = basis bouwsteen zonder extra features
