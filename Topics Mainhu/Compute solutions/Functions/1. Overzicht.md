# Azure Functions - Overzicht

## Wat is Azure Functions?

Een serverless compute service die je toestaat om kleine code snippets uit te voeren als reactie op events of op een schema, zonder servers te hoeven beheren. Het triggert je code op basis van specifieke events en vereenvoudigt data handling.

## Typische Use Cases

✅ Bestandsuploads verwerken  
✅ Real-time data streams afhandelen  
✅ Machine learning taken uitvoeren  
✅ Geplande taken draaien  
✅ Schaalbare web API's bouwen  
✅ Serverless workflows orkestreren  
✅ Reageren op database wijzigingen  
✅ Betrouwbare message systemen opzetten

## Azure Functions vs Azure Logic Apps vs WebJobs

| Feature | Azure Functions | Azure Logic Apps | Azure WebJobs |
|---------|----------------|------------------|---------------|
| **Development** | Code-first approach | Designer-first approach | Code-first approach |
| **Monitoring** | Azure Application Insights | Azure portal en Azure Monitor logs | Application Insights |
| **Execution** | Kan draaien in Azure of lokaal | Kan draaien in Azure, lokaal, of on-premises | Draait in context van App Service web app |
| **Pricing** | Pay-per-use | Op basis van execution en connector gebruik | Onderdeel van App Service plan |
| **Unieke sterkte** | Flexibiliteit en kosteneffectiviteit, veel ondersteunde talen, gebouwd op WebJobs SDK | Uitgebreide integratie mogelijkheden met grote collectie connectors | Ideaal voor taken gerelateerd aan bestaande App Service app en meer controle over code die luistert naar events |
