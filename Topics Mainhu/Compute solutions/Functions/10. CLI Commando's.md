# CLI Commando's

## Function App Plans

### Plan maken
```bash
az functionapp plan create \
    --name MyPlan \
    --resource-group MyResourceGroup \
    --sku Y1 \
    --is-linux true
```

**SKU Opties:**
- F1 (Free)
- D1 (Shared)
- B1 (Basic Small), B2 (Basic Medium), B3 (Basic Large)
- S1 (Standard Small)
- P1V2 (Premium V2 Small)
- I1 (Isolated Small), I2 (Isolated Medium), I3 (Isolated Large)
- K1 (Kubernetes)

### Plan updaten
```bash
az functionapp plan update \
    --name MyPlan \
    --sku Y2
```

### Plans ophalen
```bash
# Function app plans
az functionapp plan list --resource-group MyResourceGroup

# App service plans
az appservice plan list --resource-group MyResourceGroup

# Consumption plans
az functionapp plan list \
    --resource-group MyResourceGroup \
    --query "[?sku.family=='Y'].{PlanName:name,Sites:numberOfSites}" \
    --output table

# Premium plans
az functionapp plan list \
    --resource-group MyResourceGroup \
    --query "[?sku.family=='EP'].{PlanName:name,Sites:numberOfSites}" \
    --output table
```

## Function Apps

### Function app maken
```bash
# Consumption plan
az functionapp create \
    --name MyFunctionApp \
    --resource-group MyResourceGroup \
    --storage-account mystorageaccount \
    --consumption-plan-location eastus \
    --runtime dotnet \
    --functions-version 3
```

### Function app details bekijken
```bash
az functionapp show \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

### Hosting plan type ophalen
```bash
appServicePlanId=$(az functionapp show \
    --name MyFunctionApp \
    --resource-group MyResourceGroup \
    --query appServicePlanId \
    --output tsv)

az appservice plan list \
    --query "[?id=='$appServicePlanId'].sku.tier" \
    --output tsv
```

## Application Settings

### Settings ophalen
```bash
az functionapp config appsettings list \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

### Setting toevoegen of updaten
```bash
az functionapp config appsettings set \
    --settings CUSTOM_FUNCTION_APP_SETTING=12345 \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

### Setting verwijderen
```bash
az functionapp config appsettings delete \
    --setting-names SCALE_CONTROLLER_LOGGING_ENABLED \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

## CORS

### Domain toevoegen
```bash
az functionapp cors add \
    --allowed-origins https://contoso.com \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

### Allowed origins bekijken
```bash
az functionapp cors show \
    --name MyFunctionApp \
    --resource-group MyResourceGroup
```

## Resource Management

### Resource updaten
```bash
az resource update \
    --ids RESOURCE_ID \
    --set properties.key=value
```

### Function app scale limit instellen
```bash
az resource update \
    --resource-type Microsoft.Web/sites \
    --resource-group MyResourceGroup \
    --name MyFunctionApp/config/web \
    --set properties.functionAppScaleLimit=10
```

## REST API

### Custom request uitvoeren
```bash
az rest \
    --uri /subscriptions/{subscriptionId}/resourcegroups?api-version=2019-10-01
```

### Default (host) key ophalen
```bash
subName='<SUBSCRIPTION_ID>'
resGroup=MyResourceGroup
appName=MyFunctionApp
path=/subscriptions/$subName/resourceGroups/$resGroup/providers/Microsoft.Web/sites/$appName/host/default/listKeys?api-version=2018-11-01

az rest \
    --method POST \
    --uri $path \
    --query functionKeys.default \
    --output tsv
```
