# Persistence (Gegevenspersistentie)

## Local Cache

**Niet ondersteund** voor function apps of containerized App Service apps.

Om in te schakelen:
```bash
WEBSITE_LOCAL_CACHE_OPTION = Always
```

## Persistent Storage

Wanneer persistent storage **aan** staat (⏺️ standaard voor Linux containers):
- De `/home` directory staat bestandspersistentie en deling toe
- Alle writes naar `/home` zijn toegankelijk voor alle instances
- Bestaande bestanden overschrijven `/home` contents bij start

`/home/LogFiles` blijft altijd persisteren als logging is ingeschakeld, ongeacht persistent storage status.

### Persistent Storage uitschakelen (Linux containers)

```bash
az webapp config appsettings set --settings WEBSITES_ENABLE_APP_SERVICE_STORAGE=false ...
```

## Azure Storage mounten als local share

### Ondersteunde opties
- **Azure Files**: read/write
- **Azure Blobs**: read-only (alleen voor Linux)

### Belangrijke opmerkingen

⚠️ **App backups** bevatten geen storage mounts

✅ **Custom containers** bieden lagere latency voor heavy read-only file access vergeleken met built-in Linux images die Azure Storage gebruiken

⚠️ **Storage mount changes** zullen de app herstarten

⚠️ Bij het verwijderen van Azure Storage moet je ook de mount configuratie verwijderen

⚠️ **Storage failover** vereist app restart of remounting van Azure Storage

❌ **Gebruik geen mounts voor:**
- Lokale databases
- Apps die file locks nodig hebben

### Mount configureren

```bash
# Mount toevoegen
az webapp config storage-account add \
    --custom-id <custom-id> \
    --storage-type AzureFiles \
    --share-name <share-name> \
    --account-name <storage-account-name> \
    --access-key "<access-key>" \
    --mount-path <mount-path-directory> \
    --resource-group MyResourceGroup \
    --name MyApp

# Mount controleren
az webapp config storage-account list --resource-group MyResourceGroup --name MyApp
```

## Beperkingen

❌ Map niet naar `/`, `/home`, of `/tmp` om problemen te voorkomen

🔒 Storage firewall support alleen via service en private endpoints

❌ Geen FTP/FTPS voor custom-mounted storage

💰 Azure Storage wordt apart gefactureerd van App Service

## Best Practices

✅ Plaats app en storage in dezelfde Azure regio

✅ Vermijd het regenereren van access key
