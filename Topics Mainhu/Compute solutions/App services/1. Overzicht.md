# Azure App Service - Overzicht

## Wat is Azure App Service?

Volledig beheerde hosting voor webapplicaties, inclusief websites en web-API's.

## Deployment types

- **Multi-tenant**: Je applicatie deelt resources met andere applicaties
- **Single-tenant**: App Service Environment (ASE) - je applicatie krijgt eigen dedicated resources binnen je Azure virtual network

## Rollen

- **Front ends**: Rollen die inkomende HTTP/HTTPS requests afhandelen
- **Workers**: Rollen die de klant workload hosten

## Wanneer App Service gebruiken?

✅ Webapplicaties  
✅ Web API's  
✅ Geoptimaliseerd voor web apps  
✅ Geïntegreerd met andere Azure services
