# Security

## Authentication

Bij het inschakelen van deze feature worden alle requests automatisch omgeleid naar HTTPS. Je kunt toegang beperken tot geauthenticeerde gebruikers of anonieme requests toestaan. Built-in token store voor het beheren van tokens.

Op Windows deelt middleware je app's IIS sandbox, maar op Linux of in containers draait het apart.

### Authentication Flows

OAuth stelt apps in staat om toegang te krijgen tot resources via gebruikerspermissies, zonder credentials nodig te hebben. Azure App Service beheert dit via zijn authentication module, die sessions en tokens afhandelt. Het kan requests authenticeren en niet-geauthenticeerde gebruikers omleiden (login pagina of 401). Tokens worden opgeslagen in een token store wanneer ingeschakeld.

**Let op:** Een Access Rule is vereist.

### Types

**Server-directed** (geen SDK):
- Afgehandeld door App Service
- Voor browser apps

**Client-directed** (SDK):
- Afgehandeld door de app
- Voor non-browser apps

### Flow Vergelijking

| Stap | Server-directed | Client-directed |
|------|----------------|-----------------|
| **Gebruiker inloggen** | Redirect client naar `/.auth/login/aad` (MS Identity Platform) | Client code logt gebruiker in met provider's SDK en ontvangt authentication token |
| **Na authenticatie** | Provider redirect client naar `/.auth/login/aad/callback` | Client code post token van provider naar `/.auth/login/aad` voor validatie |
| **Authenticated session** | App Service voegt authenticated cookie toe aan response | App Service retourneert zijn eigen authentication token naar client code |
| **Authenticated content** | Client bevat authentication cookie in volgende requests | Client code presenteert authentication token in `X-ZUMO-AUTH` header |

### Andere app benaderen

Voeg header toe:
```
Authorization: Bearer ${req.headers['x-ms-token-aad-access-token']}
```

### User Claims in Code

```csharp
private class ClientPrincipalClaim
{
    [JsonPropertyName("typ")] public string Type { get; set; }
    [JsonPropertyName("val")] public string Value { get; set; }
}

private class ClientPrincipal
{
    [JsonPropertyName("auth_typ")] public string IdentityProvider { get; set; }
    [JsonPropertyName("name_typ")] public string NameClaimType { get; set; }
    [JsonPropertyName("role_typ")] public string RoleClaimType { get; set; }
    [JsonPropertyName("claims")] public IEnumerable<ClientPrincipalClaim> Claims { get; set; }
}

public static ClaimsPrincipal Parse(HttpRequest req)
{
    var principal = new ClientPrincipal();

    if (req.Headers.TryGetValue("x-ms-client-principal", out var header))
    {
        var json = Encoding.UTF8.GetString(Convert.FromBase64String(header[0]));
        principal = JsonSerializer.Deserialize<ClientPrincipal>(json, new JsonSerializerOptions { PropertyNameCaseInsensitive = true });
    }

    var identity = new ClaimsIdentity(principal.IdentityProvider, principal.NameClaimType, principal.RoleClaimType);
    identity.AddClaims(principal.Claims.Select(c => new Claim(c.Type, c.Value)));

    return new ClaimsPrincipal(identity);
}
```

## Managed Identity

**Hoofd topic:** [Managed Identities](./Managed%20Identities.md)

Elke deployment slot / app heeft zijn eigen managed identity configuratie.

### REST Endpoint

Een app met managed identity definieert twee environment variables voor een endpoint. Dit endpoint kan worden gebruikt om tokens aan te vragen voor toegang tot andere Azure services:

- `IDENTITY_ENDPOINT`: endpoint waaruit apps tokens kunnen aanvragen
- `IDENTITY_HEADER`: (uuid) gebruikt om server-side request forgery (SSRF) attacks te helpen voorkomen

### Endpoint Parameters

**Vereist:**
- `resource`
- `api-version`
- `X-IDENTITY-HEADER` (header)

**Optioneel:**
- `client_id`
- `principal_id`
- `mi_res_id`

Voor user-assigned identities, include één van de optionele properties; zonder dit wordt een system-assigned identity token aangevraagd.

**Voorbeeld:**
```http
GET {IDENTITY_ENDPOINT}?resource=https://vault.azure.net&api-version=2019-08-01&client_id=XXX
X-IDENTITY-HEADER: {IDENTITY_HEADER}
```

### Managed Identity configureren

```bash
# System-assigned managed identity inschakelen
az webapp identity assign --name MyApp --resource-group MyResourceGroup

# User-assigned managed identity maken
az identity create --name MyIdentity --resource-group MyResourceGroup

# Role assignment maken
az role assignment create --assignee $principalId --scope $resourceId --role "Reader"
```

## Certificates

Een certificate is toegankelijk voor alle apps in dezelfde resource group en regio combinatie.

### Types

**🆓 Free Managed Certificate:**
- Auto vernieuwd elke 6 maanden
- Geen wildcard certificates
- Geen private DNS
- Kan niet worden geëxporteerd (**niet bruikbaar in andere apps**)
- Niet ondersteund in ASE

**💎 App Service Certificate:**
- Private certificate beheerd door Azure
- Automated certificate management
- Vernieuwing en export opties

**🔑 Key Vault:**
- Private certificates (zelfde vereisten) opslaan in Key Vault
- Automatische vernieuwing, behalve voor non-integrated certificates

```bash
az keyvault certificate create ...
az keyvault certificate get-default-policy
```

**📤 Private Certificate uploaden:**
- Vereist password-protected PFX file
- Encrypted met triple DES
- 2048-bit private key
- Alle intermediate/root certificates in de chain

**📥 Public Certificate uploaden:**
- Voor toegang tot remote resources

### Certificate toegankelijk maken

```bash
az webapp config appsettings set --settings WEBSITE_LOAD_CERTIFICATES=<comma-separated-certificate-thumbprints> --name MyApp --resource-group MyResourceGroup
```

Gebruik in code:
```csharp
X509Store.Certificates.Find(X509FindType.FindByThumbprint, "certificate-thumbprint", true)
```

## TLS Mutual Authentication

Vereist Basic+ plan; instelbaar via `Configuration > General Settings`.

TLS terminatie wordt afgehandeld door frontend load balancer. Bij het inschakelen van client certificates wordt `X-ARR-ClientCert` header toegevoegd.

```bash
az webapp update --set clientCertEnabled=true --name MyApp --resource-group MyResourceGroup
```

### Client Certificate benaderen

**C#:**
```csharp
// Client certificate forwarden van frontend load balancer
services.AddCertificateForwarding(options => { 
    options.CertificateHeader = "X-ARR-ClientCert"; 
});

// Certificate-based authentication toevoegen
services.AddAuthentication(CertificateAuthenticationDefaults.AuthenticationScheme)
    .AddCertificate();
```

**Node.js:**
```javascript
const cert = req.get('X-ARR-ClientCert');
```

## CORS

### Voor apps
```bash
az webapp cors add --allowed-origins https://example.com --name MyApp --resource-group MyResourceGroup
```

### Voor storage
```bash
az storage cors add \
    --services blob \
    --methods GET POST \
    --origins https://example.com \
    --allowed-headers '*' \
    --exposed-headers '*' \
    --max-age 200 \
    --account-name MyStorageAccount
```

### Credentials inschakelen

Om cookies of authentication tokens te kunnen verzenden, heeft de browser mogelijk de `ACCESS-CONTROL-ALLOW-CREDENTIALS` header nodig:

```bash
az resource update \
    --set properties.cors.supportCredentials=true \
    --namespace Microsoft.Web \
    --resource-type config \
    --parent sites/$appName \
    --name MyApp \
    --resource-group MyResourceGroup
```
