# Networking

## Deployment Types

- **Multi-tenant**: Je applicatie deelt resources met andere applicaties
- **Single-tenant**: App Service Environment (ASE) - je applicatie krijgt eigen dedicated resources binnen je Azure virtual network

## Networking Features

Beheer zowel inkomend (inbound) als uitgaand (outbound) netwerkverkeer.

### Inbound Features

| Feature | Use Case |
|---------|----------|
| **App-assigned address** | IP-based SSL ondersteunen; Dedicated inbound address ondersteunen |
| **Access restrictions** | Toegang beperken vanaf specifieke IP adressen |
| **Service endpoints / Private endpoints** | Toegang tot Azure Service Resources beperken tot alleen je virtual network |

### Outbound Features

| Feature | Use Case |
|---------|----------|
| **Hybrid Connections** | Veilig toegang tot on-premises systeem of service (van Azure naar On-Premises) |
| **Gateway-required VNet integration** | Toegang tot Azure of on-premises resources via ExpressRoute of VPN (twee-weg Azure-On-Premises) |
| **Virtual network integration** | Toegang tot Azure network resources |

**Verschil:**
- **Hybrid Connections**: van Azure naar On-Premises
- **Gateway**: twee-weg Azure-On-Premises

## Ingress

Beheert externe toegang tot de services die draaien in een container. Hiermee kun je definiëren hoe extern verkeer moet worden gerouteerd naar de services binnen je containerized applicatie.

Stel in op "external" om publiek verkeer toe te staan.

Ingress configuraties specificeren meestal regels voor het routeren van HTTP en HTTPS verkeer naar specifieke services op basis van factoren zoals het request path of host header.

## Default Networking Behavior

- **Free en Shared** plans gebruiken multi-tenant workers (resources worden gedeeld)
- **Basic+** plans gebruiken dedicated workers (eigen resources)
- Alle apps in hetzelfde Standard App Service plan draaien op dezelfde worker

## Outbound Addresses

Wanneer je applicatie een call maakt naar een externe service, gebruikt het een outbound IP address. Dit adres wordt gedeeld tussen alle applicaties die draaien op hetzelfde type worker VM.

### Huidige outbound IP adressen vinden

```bash
az webapp show --query outboundIpAddresses --name MyApp --resource-group MyResourceGroup
```

### Alle mogelijke outbound IP adressen vinden

```bash
az webapp show --query possibleOutboundIpAddresses --name MyApp --resource-group MyResourceGroup
```
