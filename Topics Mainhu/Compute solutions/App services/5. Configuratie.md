# Configuratie

App settings zijn altijd encrypted when stored (encrypted-at-rest).

App Service geeft app settings door aan de container met de `--env` flag om environment variables in te stellen.

App Settings en Connection Strings worden ingesteld bij app startup en **triggeren een restart wanneer gewijzigd**. Ze overschrijven settings in `Web.config` of `appsettings.json`.

## Belangrijke Settings

### Always On
- Houdt app geladen
- Standaard uit en app unloadt na 20 minuten inactiviteit
- Nodig voor:
  - Application Insights Profiler
  - Continuous WebJobs
  - WebJobs getriggerd door CRON expressie

### ARR Affinity
In een multi-instance deployment, zorgt ervoor dat de client wordt gerouteerd naar hetzelfde instance voor de duur van de sessie.

## App Settings

Configuratie data is hiërarchisch (settings kunnen sub-settings hebben).

In Linux moet een nested setting name zoals `ApplicationInsights:InstrumentationKey` geconfigureerd worden als `ApplicationInsights__InstrumentationKey`. Dots (`.`) worden vervangen door `_`.

```csharp
// az webapp config appsettings set --settings MySetting="<value>" MyParentSetting__MySubsetting="<value>" ...
string mySettingValue = Configuration["MySetting"];
string myParentSettingValue = Configuration["MyParentSetting/MySubSetting"]; // zelfde als "MyParentSetting:MySubSetting" en "MyParentSetting__MySubSetting"
```

### Settings opslaan en laden

```bash
# Opslaan
az webapp config appsettings list --name $appName --resource-group $resourceGroup > settings.json

# Laden
az webapp config appsettings set --resource-group $resourceGroup --name $appName --settings @settings.json
```

```json
// settings.json
[
  { "name": "key1", "value": "value1", "slotSetting": false },
  { "name": "key2", "value": "value2" }
]
```

## App Settings vanuit Key Vault / App Configuration

### Key Vault
Vereisten: Geef je app toegang tot Key Vault via managed identity

```bash
# Key Vault secret

```

```bash

```

## Connection Strings

Connection strings krijgen een prefix met connection type. Vergelijkbaar met hoe ze worden ingesteld in `Web.config` onder `<connectionStrings>`.

```csharp
// az webapp config connection-string set --connection-string-type SQLServer --settings MyDb="Server=myserver;Database=mydb;User Id=myuser;Password=mypassword;" ...
string myConnectionString = Configuration.GetConnectionString("MyDb");
string myConnectionStringVerbose = Configuration.GetConnectionString("SQLCONNSTR_MyDb"); // Zelfde als hierboven
string myConnectionStringEnv = Environment.GetEnvironmentVariable("SQLCONNSTR_MyDb"); // Zelfde als hierboven
```

### Connection Strings opslaan en laden

```bash
# Opslaan
az webapp config connection-string list --name $appName --resource-group $resourceGroup > conn-settings.json

# Laden
az webapp config connection-string set --resource-group $resourceGroup --name $appName --settings @conn-settings.json
```

```json
// conn-settings.json
[
  {
    "name": "name-1",
    "value": "conn-string-1",
    "type": "SQLServer",
    "slotSetting": false
  },
  {
    "name": "name-2",
    "value": "conn-string-2",
    "type": "PostgreSQL"
  }
]
```

## General Settings

```bash
az webapp config set --name $appName --resource-group $resourceGroup \
    --use-32bit-worker-process [true|false] \
    --web-sockets-enabled [true|false] \
    --always-on [true|false] \
    --http20-enabled \
    --auto-heal-enabled [true|false] \
    --remote-debugging-enabled [true|false] \ # schakelt zichzelf uit na 48 uur
    --number-of-workers

az webapp config appsettings set --name $appName --resource-group $resourceGroup \
    --settings \
        WEBSITES_PORT=8000 \
        PRE_BUILD_COMMAND="echo foo, scripts/prebuild.sh" \
        POST_BUILD_COMMAND="echo foo, scripts/postbuild.sh" \
        PROJECT="<project-name>/<project-name>.csproj" \ # Multi-project solutions deployen
        ASPNETCORE_ENVIRONMENT="Development" \
        # Custom environment variables
        DB_HOST="myownserver.mysql.database.azure.com"
        # Verifieer op: https://<app-name>.scm.azurewebsites.net/Env
```

## Handler Mappings

Voeg custom script processors toe om requests voor specifieke bestandsextensies af te handelen.

- **Extension**: De bestandsextensie die je wilt afhandelen, zoals _\*.php_ of _handler.fcgi_
- **Script processor**: Het absolute pad van de script processor. Requests naar bestanden die matchen met de extensie worden verwerkt door de script processor. Gebruik pad `D:\home\site\wwwroot` om te verwijzen naar je app's root directory
- **Arguments**: Optionele command-line arguments voor de script processor

## URL Path mappen naar Directory

```json
// json.txt
[
  {
    "physicalPath": "site\\wwwroot\\public", // serve app vanuit /public in plaats van root (site\\wwwroot)
    "preloadEnabled": false,
    "virtualDirectories": null,
    "virtualPath": "/" // elk pad kan worden gemapped
  }
]
```

```bash
az resource update --set properties.virtualApplications=@json.txt --resource-type Microsoft.Web/sites/config --resource-group $resourceGroup --name $appName
```

Dit werkt voor zowel Windows als Linux apps.

## CLI Commando's

```bash
# App settings instellen
az webapp config appsettings set --name MyApp --resource-group MyResourceGroup --settings KEY=VALUE

# Connection strings instellen
az webapp config connection-string set --name MyApp --connection-string-type SQLAzure --settings NAME=CONNECTION_STRING --resource-group MyResourceGroup

# Web app details bekijken
az webapp show --name MyApp --resource-group MyResourceGroup
```
